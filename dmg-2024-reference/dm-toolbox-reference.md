## 難易度クラス（DC）早見表

### 基本DC

| タスクの難易度 | DC |
|-------------|---|
| Very Easy | 5 |
| Easy | 10 |
| Medium | 15 |
| Hard | 20 |
| Very Hard | 25 |
| Nearly Impossible | 30 |

### 使用ガイドライン

**Very Easy (DC 5)**
- 誰でもできる可能性が高い
- 例: 開いているドアを押す、簡単な文章を読む

**Easy (DC 10)**
- 訓練された者なら容易
- 例: 馬に乗る、簡単な罠を見つける

**Medium (DC 15)**
- 適度な挑戦、訓練が必要
- 例: 壁をよじ登る、複雑な罠を解除

**Hard (DC 20)**
- 非常に困難、熟練者でも失敗する可能性
- 例: 断崖を登る、巧妙に隠された罠を見つける

**Very Hard (DC 25)**
- ほぼ不可能に近い
- 例: 天井を渡る、超高度な罠を解除

**Nearly Impossible (DC 30)**
- 伝説級の偉業
- 例: オーバーハングの崖を登る

## アクション早見表

### よく使うアクション

| アクション | 説明 |
|----------|------|
| Attack | 攻撃を行う |
| Dash | 移動速度の2倍移動 |
| Disengage | 機会攻撃を誘発せずに移動 |
| Dodge | 攻撃者に不利を与え、Dexセーブに有利 |
| Help | 味方の判定に有利を与える |
| Hide | Dexterity (Stealth)判定 |
| Ready | トリガーで反応を準備 |
| Search | Wisdom (Perception) or Intelligence (Investigation) |
| Study | 知識判定（Arcana, History, etc.） |
| Utilize | アイテムや環境を使用 |

### D&D 2024版の新アクション
- **Influence**: 社交的影響（Persuasion, Deceptionなど）
- **Magic**: 呪文発動のアクション
- **Study**: 新設（旧Searchを含む）

## 状態（Conditions）早見表

### 主要な状態

**Blinded（盲目）**
- 視覚に基づく判定に自動失敗
- 攻撃ロールに不利
- 対象への攻撃に有利

**Charmed（魅了）**
- 魅了した者を攻撃できない
- 魅了した者の社交判定に有利

**Frightened（恐怖）**
- 恐怖源が視界内の間、判定と攻撃に不利
- 恐怖源に近づく移動不可

**Grappled（つかまれ）**
- 移動速度が0
- Escape: Athletics or Acrobatics対決

**Incapacitated（無力化）**
- アクションとBonus Actionを取れない

**Invisible（不可視）**
- 攻撃ロールに有利
- 対象への攻撃に不利

**Paralyzed（麻痺）**
- Incapacitated、話せない
- 自動失敗: Str, Dex save
- 攻撃に有利、5フィート以内からクリティカル

**Poisoned（毒状態）**
- 攻撃ロールと判定に不利

**Prone（伏せ）**
- 移動速度半分で立ち上がる
- 攻撃ロールに不利
- 5フィート以内から有利、遠隔は不利

**Restrained（拘束）**
- 移動速度が0
- 攻撃ロールに不利
- 対象への攻撃に有利
- Dex saveに不利

**Stunned（朦朧）**
- Incapacitated、話せない、移動不可
- 自動失敗: Str, Dex save
- 攻撃に有利

**Unconscious（気絶）**
- Incapacitated、伏せ、話せない、移動不可
- アイテムを落とす
- 自動失敗: Str, Dex save
- 攻撃に有利、5フィート以内からクリティカル

**Exhaustion（疲労）**（新システム）
- レベル1～10の段階制
- 各レベル: d20ロールに-1ペナルティ
- レベル5で移動速度0
- レベル10で死亡

## 社交遭遇ガイド

### NPC態度（初期）

| 態度 | 説明 | DC修正 |
|-----|------|-------|
| Hostile（敵対的） | 協力しない、攻撃的 | +5 |
| Unfriendly（非友好的） | 疑念を持つ | +2 |
| Indifferent（中立） | 特に興味なし | +0 |
| Friendly（友好的） | 好意的 | -2 |
| Helpful（助けになる） | 積極的に協力 | -5 |

### 態度を変える判定

**使用技能**:
- **Persuasion**: 正直な説得、交渉
- **Deception**: 嘘、ごまかし
- **Intimidation**: 脅迫、威圧
- **Performance**: 娯楽、感動

**DC**: 15 + 態度修正

**成功**: 1段階改善（Hostile → Unfriendly）
**失敗（5以上）**: 1段階悪化
**クリティカル成功**: 2段階改善

### NPCが知っている情報の段階

**自動的に話す**:
- 一般常識レベル
- 誰でも知っている

**DC 10-12で話す**:
- ある程度知られている
- 信頼できる相手に話す

**DC 15-18で話す**:
- 秘密だが、代償次第で
- 個人的な情報

**DC 20+または特別な条件**:
- 深刻な秘密
- 命に関わる情報

## 探索と発見

### 探索の種類

**Passive Perception**
- 常時有効
- 10 + Perception修正
- 罠や隠れた敵の自動発見

**Active Search**
- アクションを使用
- Perception or Investigation判定
- より詳細な情報

### 隠されたものの難易度

| 隠し方 | DC |
|-------|---|
| 簡単に隠した | 10 |
| 注意深く隠した | 15 |
| 専門的に隠した | 20 |
| ほぼ不可能 | 25+ |

### 発見の段階設定

**自動発見**:
- 部屋に何があるか（大まかに）
- 明らかな脅威

**DC 10-12**:
- 重要な手がかり
- 隠された出口（注意深く隠していない）

**DC 15-18**:
- 隠された宝
- 巧妙な罠

**DC 20+**:
- 秘密の部屋
- 非常に巧妙な仕掛け

## 追跡（Chases）

### 簡易ルール

**イニシアチブ順で移動**
1. 追う側と逃げる側がDash
2. 各ターン、障害物や判定
3. 距離が0 → 捕獲
4. 距離が一定以上 → 逃走成功

### Exhaustion（疲労）ルール
- Dashを連続で行う → 各ターン終了時、DC 10 Con save
- 失敗 → 1レベル疲労
- 5レベル疲労 → 移動速度0、追跡失敗

### 追跡中の障害（d6例）

1. **群衆**: Dex (Acrobatics) DC 12
2. **障害物（箱など）**: Athletics DC 12
3. **狭い路地**: Dex save DC 12
4. **水たまり**: Dex save DC 10
5. **階段**: Athletics DC 10
6. **閉じたドア**: Strチェック DC 15

## 罠

### 罠の難易度

**発見DC**:
- 簡単な罠: DC 10
- 標準的な罠: DC 15
- 巧妙な罠: DC 20

**解除DC**:
- 簡単な罠: DC 10
- 標準的な罠: DC 15
- 複雑な罠: DC 20

### 即興罠の設計

**Step 1: トリガー**
- 踏み板
- トリップワイヤー
- ドアの開放
- 特定のアイテムを取る

**Step 2: 効果**
- ダメージ（レベル×1d10程度）
- 状態異常（Poisoned, Restrainedなど）
- アラーム

**Step 3: セーブ/回避**
- Dexセーブでダメージ半減
- または、Passive Perceptionで自動発見

**例**:
```
毒矢の罠
- トリガー: トリップワイヤー
- 発見: DC 15 Perception
- 解除: DC 15 Thieves' Tools
- 効果: +5 to hit, 2d10 piercing + DC 12 Con save or Poisoned
```

## ハザード（環境的危険）

### よくあるハザード

**火災**
- ラウンド開始時、火の中: 1d10 fire damage
- Dex save DC 12で回避可能

**氷**
- 滑りやすい地面: Dex save DC 10 or Prone
- 移動速度半分

**暗闇**
- 視覚に基づく判定に不利
- 暗視なしで攻撃に不利

**濃霧**
- 視界が重度に遮られる（5-20フィート）
- 遠隔攻撃に不利

**強風**
- 遠隔攻撃に不利
- 飛行困難（判定必要）

**落下**
- 1d6 bludgeoning per 10 feet
- 最大20d6（200フィート）

## 即興判定ガイド

### 「できますか？」への回答

**Step 1: 可能性を判断**
```
不可能 → "No, but..."（代替案提示）
自動成功 → "Yes, and..."（追加の良い結果）
判定必要 → DC設定
```

**Step 2: 適切な技能/能力値**
```
身体的 → Str, Dex, Con
精神的 → Int, Wis, Cha
複数該当 → プレイヤーの説明次第
```

**Step 3: DC設定**
```
簡単 → DC 10
普通 → DC 15
難しい → DC 20
```

**Step 4: 結果の解釈**
```
成功 → 意図した結果
失敗 → "Fail Forward"（前進する失敗）
Critical → 予想以上の結果（良い/悪い）
```

## 「ルールが分からない」時の対応

### その場での裁定

**DMG 2024の原則**:
1. **ゲームを止めない**: すぐに裁定
2. **公平に**: 全員に同じルール
3. **後で確認**: セッション後に正式ルールをチェック
4. **次回から修正**: 今回は裁定通り

**裁定の例**:
```
プレイヤー: 「この能力使えますか？」
DM（ルールが不明）: 「今回は[判定/OK/NG]で。
                     セッション後、正式ルール確認します」
```

## "Rule of Cool"（ルール・オブ・クール）

### 原則
**面白さ > ルールの厳密さ**（バランス崩壊しない範囲で）

### 適用例

**プレイヤー**: 「シャンデリアのロープを切って、
           敵の上に落とせますか？」

**ルール厳密**: そのようなルールはない → NG

**Rule of Cool**: 面白い！
```
DM: 「いいですね！Athletics判定DC 15で。
     成功したら、敵にDex save DC 13。
     失敗したら3d6 bludgeoning＋Prone」
```

### 注意点
- **バランス崩壊は避ける**: 毎回使える裏技にしない
- **公平性**: 敵も同じことができる
- **前例を作る**: 次回も同じ裁定

## セッション中のよくある状況

### プレイヤーが分裂した

**対処法**:
1. 両方のグループを交互に処理
2. 時間制限を設ける（各5-10分）
3. 合流を促す展開

### プレイヤーが議論で停滞

**対処法**:
1. タイマー設定（5分など）
2. 「何か起きる」（敵の増援など）
3. グループ判定で決定

### ルールで議論

**対処法**:
1. 即座に裁定（DMの判断）
2. 「セッション後に確認」を約束
3. プレイを続行

### プレイヤーが退屈そう

**対処法**:
1. そのプレイヤーに焦点を当てる
2. アクション場面を増やす
3. 休憩を取る

## クイックリファレンス：遭遇バランス

### 1日の遭遇数（目安）

**DMG 2024**:
- Medium遭遇 6-8個/日
- Hardyを混ぜる場合は減らす
- Short Restを2-3回

### 遭遇難易度（4人パーティ）

**XP予算（レベル1の例）**:
- Easy: 100 XP (25/人)
- Medium: 200 XP (50/人)
- Hard: 300 XP (75/人)
- Deadly: 400 XP (100/人)

**実践的判断**:
```
Easy: 緊張感なし、リソース消費最小
Medium: 標準的な挑戦
Hard: リソースをかなり消費
Deadly: TPKの危険あり
```

## まとめ：セッション中のチートシート

### 困った時の対応

| 状況 | 対応 |
|-----|-----|
| DC分からない | 15にする |
| ルール不明 | その場で裁定、後で確認 |
| 遭遇が簡単すぎ | 増援追加 |
| 遭遇が難しすぎ | 敵撤退、味方登場 |
| プレイヤーが停滞 | 時間制限、何か起きる |
| 予想外の行動 | "Yes, and..." or 判定 |

### DMの心得

1. **楽しさ最優先**
2. **即興を恐れない**
3. **"Say Yes or Roll"**
4. **"Fail Forward"**
5. **Rule of Cool**
6. **公平に、でも柔軟に**
