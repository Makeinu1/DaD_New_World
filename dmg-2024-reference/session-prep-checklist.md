# セッション準備チェックリスト（DMG 2024準拠）

このドキュメントは、DMG 2024の**The One-Hour Guideline**と実践的アドバイスに基づいた、セッション準備のためのチェックリストです。

## The One-Hour Guideline とは

**DMG 2024 Chapter 1より**:
> 1時間のプレイで、平均的なグループは以下を達成できる：
> - 戦闘遭遇 1～2個
> - 社交遭遇 2～3個
> - 探索シーン 3～4個
> - または、これらの混合

このガイドラインを使って、**予定時間から逆算**してセッション内容を計画します。

## セッション時間別コンテンツ量

### 2時間セッション
```
1時間 ÷ 1時間 = 2個分のコンテンツ

推奨構成:
- 導入: 社交遭遇 1個（20分）
- 展開: 探索 or 戦闘 1個（60分）
- 結末: ロールプレイとまとめ（20分）
- 予備: 20分
```

**準備すべきもの**:
- [ ] 導入NPC 1人
- [ ] メイン遭遇 1個（詳細）
- [ ] 報酬

```

- クライマックス: 45分
- 結末とまとめ: 15分
```

**準備すべきもの**:
- [ ] フック提示
- [ ] 遭遇 3～4個

## DMG 2024の重要なアドバイス

### 準備のバランス

#### ❌ 過剰準備（Over-Preparation）
- すべてのNPCの詳細な背景
- 使わないかもしれない部屋の細部
- プレイヤーが行かない場所の地図

**なぜダメ？**: プレイヤーは予想外の行動をするため、無駄になる可能性大

#### ❌ 過少準備（Under-Preparation）
- 遭遇の内容が未定
- NPCの動機が不明
- 報酬を決めていない

**なぜダメ？**: セッション中の混乱、ゲームの停滞

#### ✅ 適切な準備（Right Preparation）
- **必須事項を押さえる**: 次セクション参照
- **柔軟性を残す**: プレイヤーの選択を受け入れる余地
- **即興の準備**: ランダム表、汎用NPC名

## 必須準備項目（最低限これだけは）

### セッション開始前に絶対必要

#### 1. セッションの目標
```
□ このセッションで何を達成するか、1～2文で書く

例:
「PCたちは盗賊団のアジトを見つけ、リーダーと対峙する。
 同時に、村を襲う真の黒幕の存在に気づく。」
```

#### 2. フック/導入
```
□ セッション開始時、プレイヤーに何を提示するか

例:
「前回のセッション終了時、村長から緊急の依頼を受けた。
 今朝、また盗賊団の襲撃があり、負傷者が出た。」
```

#### 3. メイン遭遇
```
□ このセッションの「山場」となる遭遇

戦闘なら:
- 敵の種類と数
- 簡単なマップ
- 特殊な戦術や環境要素

社交なら:
- NPCの動機と性格
- 成功/失敗の結果
- DC目安
```

#### 4. 報酬
```
□ セッション終了時の報酬

最低限:
- XPまたはマイルストーンレベルアップの有無
- 金銭のおおよその額
```

### あると良いもの

- [ ] サブ遭遇 1～2個（時間に余裕があれば）
- [ ] ランダムNPC名リスト
- [ ] 次回への引き継ぎメモ
- [ ] プレイヤーの前回行動の復習

## プロジェクトでの準備ワークフロー

### 新セッション準備の流れ

#### Week 1: 企画
```
1. adventures/session-XX/ フォルダ作成
2. overview.md に概要記入
   - 前提（Premise）
   - フック（Hook）
3. 時間配分計算（One-Hour Guideline使用）
```

#### Week 2: 詳細設計
```
4. encounters.md に遭遇詳細
   - 戦闘遭遇
   - 社交遭遇
   - 探索遭遇
5. rewards.md に報酬
6. 必要なNPC/場所を作成・更新
```

#### セッション直前
```
7. overview.md のチェックリスト確認
8. 最終リハーサル（導入部分）
9. 物理/デジタル準備
```

#### セッション後
```
10. セッションメモを記録
11. 即興追加分を正式に追加
12. 次回の方向性メモ
```

## 時間節約のヒント（DMG 2024より）

### 準備時間を節約
1. **既存リソースを再利用**
   - 過去のNPCを別の場所で再登場
   - マップを使い回し（環境を変えるだけ）
   - モンスターの再スキン（統計は同じ、見た目だけ変更）

2. **ジェネレーター活用**
   - ランダムNPC名
   - ランダム宝物
   - ランダムダンジョン

3. **プレイヤーに手伝ってもらう**
   - 前回のあらすじ説明を頼む
   - 戦闘マップのセットアップ
   - NPCの演技（一部）

### セッション中の時間節約
1. **戦闘のスピードアップ**
   - イニシアチブ順をメモ
   - プレイヤーのターンが来る前に考えさせる
   - モンスターの行動を事前に決める

2. **決定の迅速化**
   - 議論が長引いたら判定で決める
   - タイマー使用（任意）

3. **ルール裁定**
   - 分からないルールは後で確認
   - その場では「今回はこうする」と決める

## よくある質問

### Q: The One-Hour Guidelineは厳密に守るべき？

**A (DMG 2024)**: 目安として使用
- グループによってペースは異なる
- 戦闘好きなグループは1時間で1戦闘のみかも
- ロールプレイ重視なら社交遭遇が長引く
- 数セッション後、自分のグループのペースを把握

**プロジェクトでの対応**:
- `campaign/concept.md` に「我々のペース」をメモ
- セッション後、実際の時間を記録

### Q: 準備が間に合わなかったら？

**A (DMG 2024)**: 正直にプレイヤーに伝える
```
「今日は準備が十分でないので、短めにしませんか？」
「もしくは、ロールプレイ重視で進めましょう」
```

**代替案**:
- ショートセッション（1～2時間）
- キャラクター中心の回（ダウンタイム活動）
- プレイヤー主導のサイドクエスト

### Q: 予定より早く終わりそうなら？

**A (DMG 2024)**: 選択肢
1. **早めに終える**: 問題なし！
2. **ボーナスコンテンツ**: 簡単なランダム遭遇
3. **ロールプレイ**: キャラクター同士の交流
4. **セッション0的な対話**: キャンペーンの方向性など

**準備**:
- バックアップ遭遇を1個用意（任意）
- ランダム表をそばに

## まとめ

**セッション準備の原則（DMG 2024）**:

1. **時間から逆算**: The One-Hour Guideline
2. **必須を押さえる**: 目標、フック、メイン遭遇、報酬
3. **柔軟性を残す**: プレイヤーの選択を受け入れる
4. **即興の準備**: ランダム表、汎用リソース
5. **完璧を求めない**: 楽しさ優先

**このチェックリストで**:
- ✅ 準備すべきことが明確
- ✅ 時間に応じた準備量を調整
- ✅ セッション中の自信が向上
- ✅ 一貫したクオリティ維持
