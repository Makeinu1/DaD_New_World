# DUNGEON MASTER'S GUIDE 2024 - リファレンス

このフォルダには、D&D 2024版 Dungeon Master's Guideの重要な情報を要約したドキュメントが含まれています。

## 📚 目的

- キャンペーン作成時のクイックリファレンス
- LLMへの学習データとしての活用
- DMが参照すべき重要なルールとガイドラインの集約

## 📖 ドキュメント構成

### 概要・全体像
- [00-overview.md](00-overview.md) - DMG 2024の章構成と基本概念
- [dmg-2024-essentials.md](dmg-2024-essentials.md) - DMG全章の要点まとめ（384ページ相当）

### 実践ガイド
- [adventure-creation-guide.md](adventure-creation-guide.md) - 冒険作成の4ステップフレームワーク
  - DMG Chapter 4準拠
  - ボトムアップ方式での実践方法
  - プロジェクトへの適用例

- [session-prep-checklist.md](session-prep-checklist.md) - セッション準備チェックリスト
  - The One-Hour Guidelineベース
  - 準備時間別のワークフロー
  - セッション時間別コンテンツ量計算

- [dm-toolbox-reference.md](dm-toolbox-reference.md) - DMツールボックス クイックリファレンス
  - セッション中に即座に参照
  - DC、状態、アクション早見表
  - ランダムNPC/遭遇生成表
  - 即興ツール集

## 🎯 使い方

### 初めてDMをする方
1. [00-overview.md](00-overview.md) でD&Dの基本構造を理解
2. [dmg-2024-essentials.md](dmg-2024-essentials.md) のChapter 1-2で基礎を学ぶ
3. [session-prep-checklist.md](session-prep-checklist.md) で最初のセッション準備

### キャンペーン作成時
1. [dmg-2024-essentials.md](dmg-2024-essentials.md) のChapter 5でキャンペーン構築の基本を確認
2. [adventure-creation-guide.md](adventure-creation-guide.md) で個別の冒険を設計
3. [dm-toolbox-reference.md](dm-toolbox-reference.md) で必要な要素（NPC、遭遇等）を作成

### セッション準備時
1. [session-prep-checklist.md](session-prep-checklist.md) で準備すべき項目を確認
2. [adventure-creation-guide.md](adventure-creation-guide.md) の4ステップで冒険を構築
3. [dm-toolbox-reference.md](dm-toolbox-reference.md) で即興用リソースを用意

### セッション中
- [dm-toolbox-reference.md](dm-toolbox-reference.md) を手元に置いて即座に参照
- DC、状態異常、NPCの即興生成に活用

### LLMへの学習データとして
- 各ドキュメントは構造化されており、LLMが参照しやすい形式
- [dmg-2024-essentials.md](dmg-2024-essentials.md) で全体像を把握
- 個別ガイドで詳細な実践方法を学習
