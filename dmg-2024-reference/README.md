## 🎯 使い方

### キャンペーン作成時
1. [05-creating-campaigns.md](05-creating-campaigns.md) でキャンペーン構築の基本を確認
2. [04-creating-adventures.md](04-creating-adventures.md) で個別の冒険設計方法を学ぶ
3. [03-dm-toolbox.md](03-dm-toolbox.md) で必要な要素を作成

### セッション準備時
1. [02-running-the-game.md](02-running-the-game.md) で判定ルールを確認
2. [quick-reference.md](quick-reference.md) でDC等を参照
3. [07-treasure.md](07-treasure.md) で報酬を決定

### LLMへの学習データとして
- 各ドキュメントは構造化されており、LLMが参照しやすい形式
- 重要な概念、ルール、ガイドラインが抽出されている
