# 冒険作成ガイド（DMG 2024 準拠）

このドキュメントは、DMG 2024のChapter 4で紹介されている**4ステップ冒険作成フレームワーク**を詳しく解説し、本プロジェクトでの実践方法を示します。

## 冒険作成の4ステップ

DMG 2024では、冒険作成を以下の4つのステップに分けています：

1. **Lay Out the Premise**（前提を設定する）
2. **Draw in the Players**（プレイヤーを引き込む）
3. **Plan Encounters**（遭遇を計画する）
4. **Bring It to an End**（結末へ導く）

---

## Step 1: Lay Out the Premise（前提を設定する）

### 目的
冒険の核となるアイデアとテーマを決定する

### 考えるべき要素

#### 1. 中心となる紛争（Central Conflict）
**問い**: この冒険で解決すべき問題は何か？

**例**:
- 村を脅かす盗賊団
- 失われた古代遺物の探索
- 政治的陰謀の暴露
- モンスターの巣窟の掃討

**プロジェクトでの記録場所**: `adventures/session-XX/overview.md` の「概要」セクション

#### 2. テーマと雰囲気（Theme & Tone）
**問い**: この冒険はどんな気分を醸し出すか？

**雰囲気の例**:
- **ホラー**: 恐怖と緊張
- **ミステリー**: 謎解きと調査
- **ヒロイック**: 壮大な戦いと勝利
- **コメディ**: 軽快で楽しい
- **ダーク**: 道徳的葛藤と苦い選択

**プロジェクトでの記録場所**: `campaign/concept.md` の「トーン」セクション

#### 3. 場所（Location）
**問い**: 冒険はどこで起こるか？

**場所の選択**:
- 既存の場所を使う: `locations/` から選択
- 新しい場所を作る: `locations/` に追加
- 複数の場所を組み合わせる

**ボトムアップ方式のヒント**: 
- 小さな場所から始める（村、ダンジョン1つなど）
- プレイヤーの興味に応じて拡張
- 詳細は必要になってから決める

#### 4. アンタゴニスト（Antagonist）
**問い**: 誰（または何）がプレイヤーに対立するか？

**アンタゴニストの種類**:
- **ヴィラン**: 知性的な敵（`npcs/villains.md`）
- **モンスター**: 野生の脅威
- **自然災害**: 環境的脅威
- **社会的障壁**: 政治、偏見など

**記録場所**: `npcs/villains.md` または各セッションの `encounters.md`

---

## Step 2: Draw in the Players（プレイヤーを引き込む）

### 目的
プレイヤーが「なぜこの冒険に参加するのか」を明確にする

### フック（Hooks）の設計

#### 良いフックの条件（DMG 2024より）

1. **明確な目的**
   - プレイヤーが何をすべきか分かりやすい
   - 「〜を見つける」「〜を倒す」「〜を救う」

2. **複数の動機**
   - 金銭的報酬
   - 名誉・評判
   - 個人的理由（復讐、家族など）
   - 善意・正義感
   - 好奇心・冒険心

3. **緊急性**
   - 「今すぐ行動する理由」がある
   - 「明日でもいい」冒険は興味を引きにくい

4. **柔軟性**
   - プレイヤーの様々なアプローチを受け入れる

#### フックの種類

##### A. クエストギバー型
NPCが直接依頼する

**例**:
```markdown
村長が冒険者たちを呼び、盗賊団退治を依頼する。
報酬は500gp＋村での評判向上。
```

**プロジェクトでの実装**:
- NPC情報: `npcs/allies.md` または `locations/starting-village/npcs.md`
- フック詳細: `adventures/hooks.md`

##### B. 偶然の遭遇型
プレイヤーが問題に偶然巻き込まれる

**例**:
```markdown
旅の途中、モンスターに襲われている商人を発見。
助けた商人から感謝と情報を得る。
```

##### C. 個人的な動機型
PCの背景に関連

**例**:
```markdown
PCの故郷の村が危機に。
家族や友人からの手紙が届く。
```

**セッション0でのすり合わせが重要**

##### D. 謎・好奇心型
未解決の謎が冒険を駆動

**例**:
```markdown
古代遺跡の地図を発見。
そこには失われた魔法のアイテムがあるという。
```

#### 社会的契約（Social Contract of Adventures）

**DMG 2024の重要な原則**:
> DMは魅力的な冒険の理由を提供する責任がある。
> プレイヤーはそのフックに乗る責任がある。

**実践**:
- フックを無視してまったく別方向に行くのは避ける（ただし、アプローチの自由は尊重）
- もしフックが機能していないと感じたら、セッション外で話し合う

**プロジェクトでの記録**: `adventures/hooks.md` にフックリストを管理

## Step 3: Plan Encounters（遭遇を計画する）

### 目的
冒険を構成する具体的なシーンと遭遇を設計する

### 遭遇の種類（DMG 2024分類）

#### 1. Combat Encounters（戦闘遭遇）
**要素**:
- 敵の構成とCR
- 戦場の環境
- 戦術と特殊能力
- **D&D 2024版要素**: 武器マスタリーを活かせる設計

**プロジェクトでの記録**: `adventures/session-XX/encounters.md` の「戦闘遭遇」セクション

**設計のコツ**:
```markdown
### 環境を活用
- 高低差: Push、Topple武器マスタリーが輝く
- 狭い空間: Slow、Sapで後衛を守る
- 障害物: 戦術的な位置取りを促す

### バランス
- Easy: ウォームアップ、リソース消費少
- Medium: 標準的な挑戦
- Hard: 緊張感のある戦い
- Deadly: クライマックス専用、要注意
```

#### 2. Social Encounters（社交遭遇）
**要素**:
- NPCの動機と態度
- 可能なアプローチ（説得、脅迫、欺瞞、取引など）
- 成功/失敗時の結果
- DC設定

**プロジェクトでの記録**: `adventures/session-XX/encounters.md` の「社交遭遇」セクション

**設計のコツ**:
```markdown
### NPCに深みを
- 何を望んでいるか？
- 何を恐れているか？
- どんな性格か？

### 複数の解決法
- 説得だけでなく、贈り物、脅迫、情報交換など
- プレイヤーの創造性を尊重

### 失敗でも前進
- 失敗してもゲームオーバーにしない
- より困難な状況で目標達成の道を残す
```

#### 3. Exploration Encounters（探索遭遇）
**要素**:
- 発見できるもの（段階的に）
- 必要な判定とDC
- 隠された情報や罠
- 環境的ハザード

**プロジェクトでの記録**: `adventures/session-XX/encounters.md` の「探索遭遇」セクション

**設計のコツ**:
```markdown
### 発見の層
1. 自動的に見つかる: 基本情報
2. 低DCで見つかる: 重要な手がかり
3. 高DCで見つかる: ボーナス情報、宝

### 複数スキルの活用
- Perception: 視覚的発見
- Investigation: 論理的推理
- Survival: 痕跡追跡
- Arcana: 魔法的手がかり
```

### 遭遇のバランスと配置

#### The One-Hour Guideline活用

**1時間で**:
- 戦闘遭遇 1～2個
- 社交遭遇 2～3個
- 探索シーン 3～4個
- または混合

**3～4時間セッション**: 6～12個の遭遇を計画

#### 遭遇の構成例

**構造の例**（3時間セッション）:
```
導入（30分）
├─ 社交遭遇: フックの提示
└─ 探索遭遇: 情報収集

展開（1時間30分）
├─ 探索遭遇: 目的地への移動中の発見
├─ 戦闘遭遇: 敵の偵察隊
└─ 社交遭遇: 中立NPCとの交渉

クライマックス（45分）
└─ 戦闘遭遇: ボス戦

結末（15分）
└─ 報酬と次回へのフック
```

**プロジェクトでの記録**: `adventures/session-XX/overview.md` の「シーン構成」と「時間配分目安」

### 技能チャレンジ（Skill Challenges）

**DMG 2024のアプローチ**:
複雑なタスクを一連の判定で解決

**構造**:
- 必要成功回数（例: 3回）
- 許容失敗回数（例: 2回）
- 使用可能な技能とDC
- 成功/失敗/部分的成功の結果

**プロジェクトでの記録**: `adventures/session-XX/encounters.md` の「技能チャレンジ」セクション

**例**:
```markdown
### 崩れる橋を渡る

**目的**: パーティ全員が無事に渡る
**複雑度**: 成功3回、失敗2回まで

**使用可能技能**:
- Acrobatics (DC 13): バランスを取って渡る
- Athletics (DC 15): 力で橋を安定させる
- Perception (DC 12): 安全なルートを見つける
- Survival (DC 14): 自然の材料で補強

**成功**: 全員無事に渡る
**失敗**: 1d6人が落下（DC 15 Dex save）
```

## Step 4: Bring It to an End（結末へ導く）

### 目的
冒険を満足のいく形で終わらせ、次への繋ぎを作る

### 結末の設計

#### 1. クライマックスの選択肢

**A. 戦闘的クライマックス**
- ボス戦
- 大規模戦闘
- 環境を活かした戦い

**B. 社交的クライマックス**
- 交渉での解決
- 裁判シーン
- 説得や取引

**C. 混合クライマックス**
- 戦闘と交渉の両方の可能性
- プレイヤーの選択で決まる

**D. 探索/謎解きクライマックス**
- パズルの最終段階
- 真実の発見

#### 2. 複数の解決法を許可

**DMG 2024の原則**: プレイヤーの創造性を尊重

**例**:
```markdown
悪のウィザードを倒すミッション

可能なアプローチ:
1. 戦闘で直接倒す
2. 説得して改心させる
3. 証拠を集めて告発する
4. 魔法のアイテムで無力化
5. 内部分裂を起こさせる
```

#### 3. 報酬

**プロジェクトでの記録**: `adventures/session-XX/rewards.md`

**報酬の種類**:
- **経験値/マイルストーン**
- **金銭**
- **マジックアイテム**（DMG Chapter 7参照）
- **社会的報酬**（評判、コネクション）
- **情報**（次の冒険への手がかり）

**バランス** (DMG 2024ガイドライン):
```markdown
レベル1キャラクター:
- 開始財産: 50-175 gp相当（クラス依存）
- セッション1終了目標: 100-200 gp相当
- マジックアイテム: なし～コモンの消耗品

レベル2-4:
- セッション報酬: 100-300 gp
- マジックアイテム: コモン～アンコモンの消耗品

レベル5+:
- Bastions導入検討
- より強力なマジックアイテム
```

#### 4. 次回への引き継ぎ

**要素**:
- **解決されたこと**: 達成感を与える
- **残る謎**: 興味を持続
- **新しいフック**: 次の冒険への導入

**プロジェクトでの記録**: `adventures/session-XX/overview.md` の「次回への引き継ぎ」セクション

**例**:
```markdown
### 解決されること
- 盗賊団のリーダーを捕らえた
- 盗まれた財宝を回収した

### 残る謎・問題
- 盗賊団の真の黒幕は誰？
- なぜこの村が狙われたのか？

### 次回のフック
- 捕らえた盗賊が謎めいた言葉を残す
- 財宝の中に奇妙な地図が...
```

## プロジェクトでの実践ワークフロー

### 新しいセッションを作成する手順

#### 1. フォルダ作成
```bash
adventures/session-XX/
├── overview.md      # 全体構成
├── encounters.md    # 遭遇詳細
└── rewards.md       # 報酬
```

#### 2. Step 1: Premise設定
`overview.md` の「概要」セクションに記入:
- 推奨レベル
- 主要な場所
- 中心となる紛争
- テーマ

#### 3. Step 2: フック設計
`adventures/hooks.md` に追加し、`overview.md` の「導入」セクションで参照:
- プレイヤーへの提示方法
- 複数の動機を用意

#### 4. Step 3: 遭遇計画
`encounters.md` に詳細記入:
- 戦闘遭遇（環境、敵、戦術）
- 社交遭遇（NPC、DC、結果）
- 探索遭遇（発見物、判定）
- 技能チャレンジ

`overview.md` の「シーン構成」で流れを整理

#### 5. Step 4: 結末設計
`overview.md` に追加:
- クライマックスの設計
- 複数の解決法
- 次回への引き継ぎ

`rewards.md` に報酬詳細

#### 6. 時間配分確認
`overview.md` の「時間配分目安」:
- The One-Hour Guidelineで計算
- 予備時間を確保

#### 7. DM準備チェックリスト
`overview.md` の最後:
- [ ] NPC統計
- [ ] マップ
- [ ] モンスター統計
- [ ] 報酬アイテム
- その他

## よくある質問とDMG 2024の回答

### Q1: プレイヤーが予想外の行動をしたら？

**A (DMG 2024)**:
- **即興を恐れない**: すべてを事前に準備する必要はない
- **"Say Yes or Roll the Dice"**: 可能な限り許可するか、判定で決める
- **Fail Forward**: 失敗しても物語を前進させる

**プロジェクトでの対応**:
- 即興で決めたことは後で `overview.md` の「セッション後の記録」に追記
- 矛盾が生じないように `campaign/world/overview.md` も更新

### Q2: 遭遇が簡単すぎた/難しすぎた場合は？

**A (DMG 2024)**:
- **戦闘中の調整**:
  - 簡単すぎる: 増援を追加、敵のHPを増やす
  - 難しすぎる: 敵の撤退、味方NPCの助け、環境変化
- **次回への学習**: 調整メモを記録

**プロジェクトでの対応**:
- `encounters.md` に「推奨される難易度調整」セクションを設ける
- 実際の結果を「セッション後の記録」に追記

### Q3: ボトムアップ方式でどこまで準備すべき？

**A (DMG 2024 + プロジェクト方針)**:
- **今必要なものだけ**: 次セッションで使う場所・NPCのみ詳細化
- **抽象的な枠組み**: より広い世界は概要のみ
- **プレイヤー主導**: 彼らの興味に応じて拡張

**実践**:
```markdown
良い例:
- 初期の村: 詳細なNPC、場所
- 隣町: 名前と距離のみ（まだ行かないなら）
- より遠い都市: 存在だけ言及

悪い例:
- 全ての都市の詳細地図を事前作成
- 使わないNPCを大量に作成
```

## 実例: サンプルセッション作成

DMG 2024の方法を使った実例

### Step 1: Premise

```markdown
## 概要
失われた井戸の調査

**推奨レベル**: 1
**主要な場所**: 初期拠点の村、近くの森
**中心となる紛争**: 村の井戸が枯れ、水源を失った
**テーマ**: ミステリーと探索、環境的脅威
```

### Step 2: Hook

```markdown
## 導入
村長エルダが冒険者を呼び、井戸枯渇の原因調査を依頼。
報酬: 200gp ＋ 村での宿泊無料

プレイヤーの動機:
- 金銭: 報酬200gp
- 善意: 村人の苦しみを見かねて
- 個人的: PC の出身村（背景に応じて）
- 好奇心: なぜ突然枯れたのか？
```

### Step 3: Encounters

```markdown
## シーン1: 村での情報収集（社交・探索）
- 村人への聞き込み（DC 10 Persuasion）
- 井戸の調査（DC 12 Investigation）
- 発見: 最近、森で奇妙な音がした

## シーン2: 森への探索（探索・遭遇）
- 痕跡追跡（DC 13 Survival）
- ランダム遭遇: ウルフ2匹（Easy戦闘）

## シーン3: 地下水脈の発見（探索・パズル）
- 隠された洞窟入口（DC 15 Perception）
- 内部の調査

## シーン4: クライマックス（戦闘）
- 地下に巣食うOoze（Medium難易度）
- 水脈を塞いでいた
- 倒すと水が戻り始める
```

### Step 4: End

```markdown
## 結末
村に戻り、報酬を受け取る
村人から感謝される（評判+1）

### 次回への引き継ぎ
- 解決: 水源回復、村は安全
- 残る謎: なぜOozeがそこに？
- 新フック: 洞窟奥にさらに深い通路が...
```

## チェックリスト: 良い冒険の条件

冒険を作成したら、このチェックリストで確認：

### 前提（Premise）
- [ ] 明確な中心紛争がある
- [ ] テーマと雰囲気が一貫している
- [ ] 場所が具体的に決まっている
- [ ] アンタゴニストが明確

### フック（Hook）
- [ ] プレイヤーが参加する理由が複数ある
- [ ] 緊急性がある（今やるべき理由）
- [ ] 様々なPCタイプに訴える
- [ ] 柔軟なアプローチを許可

### 遭遇（Encounters）
- [ ] 戦闘、社交、探索のバランス
- [ ] 各遭遇に明確な目的
- [ ] D&D 2024版要素を活用
- [ ] 時間配分が適切（One-Hour Guideline）

### 結末（Ending）
- [ ] 満足のいくクライマックス
- [ ] 複数の解決法がある
- [ ] 報酬が適切
- [ ] 次への繋ぎがある

### 全体
- [ ] セッション時間内に収まる
- [ ] DM準備が現実的
- [ ] プレイヤーの選択を尊重
- [ ] 楽しさを最優先

---

## まとめ

DMG 2024の4ステップフレームワークは：

1. **構造を提供**: 何から始めればいいか明確
2. **柔軟性を保つ**: プレイヤーの選択を尊重
3. **実用的**: すぐに使える

このプロジェクトの `adventures/` フォルダ構造はこのフレームワークに基づいており、段階的に冒険を構築できます。

**次のステップ**:
- `session-prep-checklist.md` でセッション直前準備を確認
- `dm-toolbox-reference.md` で即興に役立つツールを参照
- 実際に `adventures/session-01/` を作成開始！
