# 案4: ギルドハウス型（Bastion中心設計）

## 概要

D&D 2024の新システム「Bastion」を中核に据えたキャンペーン。プレイヤーたちが共同でギルドハウス（拠点）を設立・成長させながら、周辺のダンジョンを攻略。拠点の成長とキャラクターの成長が並行し、セッション間でも進行感がある。

**キーワード**: 拠点成長、Bastion活用、協力プレイ、長期投資

---

## 世界設定

### 都市名: ニューヘイブン（仮）

**背景**:
- 辺境の新興都市（建設後50年）
- 周辺に未開拓の遺跡・ダンジョン多数
- 冒険者を誘致して都市発展を目指す
- 冒険者ギルド設立を奨励（税制優遇）

**都市の特徴**:
- 人口: 8,000人（成長中）
- 開拓者精神旺盛
- 規制が緩い（良くも悪くも）
- 土地が比較的安価

## Bastionシステムの詳細

### Phase 0: 準備期間（レベル1-4）

**目標**: ギルド設立資金の蓄積

**活動**:
- 既存ギルドの下請け冒険者として活動
- 資金と評判を蓄積
- 土地の選定
- ギルド名の決定

**必要資金**: 合計2,000 gp（レベル4終了時）

### Phase 1: ギルド設立（レベル5）

**Bastion獲得！**

**初期施設（DMG 2024ルール）**:
- **Bedroom × 4**: 各PC用
- **Courtyard**: 共用スペース
- **Parlor**: 応接間（クエスト受付）

**場所**:
都市の冒険者地区に中規模の建物を購入or建設

**初期スタッフ**:
- 受付係・ミラ（Human、若い女性）
- 用心棒・ガロック（Half-Orc、元兵士）

### Phase 2: ギルド成長（レベル6-10）

**追加施設の選択**:

プレイヤーは成長に応じて施設を追加（DMG 2024のBastion Orders）:

1. **Workshop**（レベル6）: 装備クラフト
2. **Library**（レベル7）: 知識と研究
3. **Barracks**（レベル8）: 雇用兵士
4. **Pub**（レベル9）: 情報収集と収入源
5. **Arcane Study**（レベル10）: 魔法研究

**Bastion Orders（セッション間活動）**:

各PCは以下の活動から1つ選択:

- **Craft（Workshop）**: マジックアイテムor装備作成
- **Research（Library）**: 次のダンジョン情報、アドバンテージ獲得
- **Recruit（Barracks）**: NPCの一時雇用
- **Trade（Pub）**: 追加収入（1d4 × 100 gp）
- **Emissary（Parlor）**: 都市政治への影響力

### Phase 3: 名門ギルド（レベル11+）

**追加施設**:
- **Teleportation Circle**（レベル11）: 遠隔地への移動
- **Guildhall**（レベル12）: サブギルド設立
- **Sanctuary**（レベル13）: 神聖な保護
- **War Room**（レベル14）: 軍事作戦計画

**影響力**:
ギルドが都市で最も力を持つ組織の1つに

## キャンペーン構造

### Phase 1: 見習い時代（レベル1-4）

**目標**:
- 資金2,000 gp蓄積
- 評判の確立
- パーティの結束

**典型的な流れ**:
1. 既存ギルドからクエスト受注
2. ダンジョン探索
3. 報酬を「ギルド設立資金」に積立
4. 都市での土地探し
5. レベル4終了時、ギルド設立決定

**モチベーション**:
「自分たちのギルドを持つ」という明確な目標

### Phase 2: ギルド運営（レベル5-10）

**新要素**: Bastionシステム全開

**セッション構成**:
1. **ギルドパート（30分）**: Bastion Ordersの結果発表、新クエスト受付
2. **都市パート（30分）**: 買い物、情報収集、政治
3. **ダンジョンパート（90分）**: 選択したダンジョン探索
4. **帰還パート（30分）**: 報告、報酬、次回Bastion Orders選択

**ギルドの成長**:
セッションごとに施設が増え、できることが増える

**例**:
- セッション5: Workshop追加 → Crafting可能に
- セッション7: Pub追加 → 情報収集が容易に、収入源
- セッション10: Barracks追加 → NPC仲間雇用可能

### Phase 3: 名門ギルド（レベル11+）

**目標**:
- 都市で最も有名なギルドに
- 遠方への影響力拡大
- 大規模な脅威への対処

**新要素**:
- 支部ギルドの設立（他都市）
- 政治的影響力（都市評議会への参加）
- サブギルドマスター（NPCの育成）

## セッション例

### セッション1: 「ギルドへの第一歩」（レベル1、3時間）

**フック**:
PCたちは様々な理由でニューヘイブンに到着。既存ギルド「銀の盾」の新人募集に応募。

**構成**:
1. **導入（30分）**: 都市到着、ギルド面接、パーティ結成
2. **初任務説明（15分）**: 「下水道のGiant Rat駆除」
3. **ダンジョン探索（90分）**: 都市地下下水道
4. **帰還と報酬（30分）**: 報告、給金50 gp（積立開始）
5. **ギルド設立の夢（15分）**: 先輩冒険者から「いずれ自分のギルドを」と励まし

**特別要素**:
- 「ギルド設立資金: 50/2000 gp」表示
- 都市で売りに出ている建物を見学

---

### セッション6: 「我らがギルドハウス」（レベル5、4時間）

**前提**: レベル5到達、資金2,000 gp達成

**フック**:
ついにギルドハウスを購入！初のBastionセッション。

**構成**:
1. **ギルド設立式（45分）**:
   - 建物購入手続き
   - ギルド名の正式決定（プレイヤー投票）
   - 都市評議会への登録
   - 初期施設の確認（Bedroom、Courtyard、Parlor）

2. **初クライアント（30分）**:
   - 応接間で初のクライアント受付
   - 依頼「北のドラゴンの古巣調査」

3. **Bastion Orders選択（15分）**:
   - 各PCが最初のOrderを選択
   - Workshop建設を決定（次セッションで完成）

4. **ダンジョン探索（90分）**: ドラゴンの古巣へ

5. **帰還とギルド生活（30分）**:
   - 初報酬をギルド金庫へ
   - 次回Bastion Ordersの計画

## メリット・デメリット

### メリット

#### 1. D&D 2024の新システムを最大活用
- Bastionシステムの全機能
- 2024版の目玉を体験
- 他のキャンペーンとの差別化

#### 2. セッション間の進行感
- Bastion Ordersで常に進行
- 「待ちきれない」感じ
- モチベーション維持

#### 3. 協力プレイの実感
- 共同の目標（ギルド成長）
- 役割分担（各PCが得意分野）
- チームビルディング

#### 4. 長期投資の楽しさ
- レベル1から「いつか自分のギルドを」
- 達成感（レベル5で実現）
- 継続的な成長

#### 5. ドロップイン・ドロップアウトの自然な説明
- 「ギルドメンバー」で統一
- 不在時は「別任務」「ギルド業務」
- 新規PCは「新メンバー募集」

### デメリット

#### 1. レベル5まではBastionなし
- レベル1-4は従来型
- この期間のモチベーション維持が課題

**緩和策**:
- 「ギルド設立資金」という明確な目標
- レベル3あたりで土地の下見イベント
- 資金の可視化（進捗バー）

#### 2. Bastionルールの学習コスト
- DMとプレイヤーがルールを理解必要
- 初回は時間がかかる

**緩和策**:
- セッション0でルール説明
- 簡易化したルールシート配布
- 最初は選択肢を限定

#### 3. ギルド管理の負担
- 施設、スタッフ、資金の管理
- DMの追加作業

**緩和策**:
- スプレッドシートでの管理
- プレイヤーに一部委任（会計係等）
- GitHubでの共有

#### 4. ダンジョンが添え物になるリスク
- ギルド成長が主、ダンジョンが従
- 冒険の緊張感が薄れる可能性

**緩和策**:
- ダンジョンからの報酬をギルドに直結
- 「ギルドの評判」システム（成功で上昇）
- ダンジョンでしか得られないものを設定

## 運用方法

### ドロップイン・ドロップアウト

**完璧な説明**:
```
全員が同じギルドメンバー
参加可能: 「今日の任務に参加」
不在: 「別の任務で出張中」「ギルド業務担当」
新規PC: 「新メンバーの加入」
```

**Bastion Ordersの処理**:
不在PCも自動的にOrdersを実行（事前選択or DM判断）

### DM交代

**方法1: ダンジョン担当制**
- 各DMが特定ダンジョンを担当
- ギルドパートは共通

**方法2: ギルドマスター交代制**
- セッションごとにギルドマスター（DM）交代
- 他DMはサブギルドマスター（プレイヤー）として参加

**共有事項**:
- ギルドの財政状況
- 施設リスト
- スタッフNPCリスト
- Bastion Orders履歴

### セッション記録

**ギルド議事録形式**:
```markdown
## ギルド議事録: セッションXX
- 日付: [日付]
- 参加メンバー: [PC名]
- 任務: [ダンジョン名]
- 成果: [財宝、XP]
- ギルド資金: [現在額]
- Bastion Orders:
  - PC-A: Research（完了）
  - PC-B: Craft（進行中）
- 次回: [計画]
```

## まとめ

### この案が向いているグループ

✅ **拠点成長が好き**
✅ **協力プレイを楽しみたい**
✅ **D&D 2024の新要素を試したい**
✅ **長期的な投資の達成感**
✅ **管理・経営要素に興味**

### この案が向いていないグループ

❌ **純粋なダンジョンクロールが好き**
❌ **ルール学習が面倒**
❌ **Bastionに興味がない**
❌ **レベル1から特別感が欲しい**

### 推奨度

**グループ適合性**: ★★★★☆
**DM負担**: ★★★☆☆（Bastion管理が追加）
**長期継続性**: ★★★★★（モチベーション維持容易）
**ユニーク性**: ★★★★☆（Bastion活用）
**D&D 2024活用**: ★★★★★（最高）

**総合評価**: ★★★★☆

D&D 2024の新システムを最大限活用したい場合に最適。ギルド成長という明確な目標でモチベーション維持が容易。協力プレイの実感が強い。ただし、Bastionルールの学習とレベル1-4期間の工夫が必要。
