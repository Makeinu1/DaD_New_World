# 案6: ハイブリッド案 - ギルド都市とその迷宮

## 概要

案2「迷宮に囲まれた自由都市」と案4「ギルドハウス型（Bastion中心）」の長所を統合した総合案。中央都市を拠点に周辺ダンジョンを攻略しながら、レベル5以降は自分たちのギルドハウス（Bastion）を成長させる。戦闘・探索・ロールプレイのバランスが良く、DM交代とドロップイン・ドロップアウトに最適化。

**キーワード**: バランス型、段階的成長、DM交代容易、ストーリー性、D&D 2024フル活用

---

## 世界設定

### 都市名: フリーダム・クロス（仮）

**立地**:
- 4-6つの古代ダンジョンの交差点に建設された自由都市
- 各ダンジョンは異なる時代・文明の遺産
- 交易路の要衝でもある

**歴史**:
- 100年前、冒険者たちが開拓
- ダンジョンから湧き出る財宝で繁栄
- 現在は冒険者ギルドが都市の主要産業
- 様々な種族が共存する多文化都市

**政治体制**:
- 自由都市（独立）
- 冒険者ギルド評議会が統治
- 大手ギルド3つが権力を握る
- 新興ギルドが台頭のチャンス

**特徴**:
- ダンジョン探索が日常
- 冒険者が社会的地位を持つ
- 魔法アイテム流通が盛ん
- 危険と富が隣り合わせ

## キャンペーン構造

### 3つのPhase設計

#### Phase 1: ギルド見習い時代（レベル1-4）

**所属**: 既存の大手ギルド「銀の盾団」の見習い

**活動内容**:
- 小規模ダンジョンの初級エリア攻略
- ギルドからの依頼遂行
- 都市での人脈構築
- 資金と実績の蓄積

**ゴール**:
- レベル5到達
- ギルド設立資金の獲得（1000gp×人数）
- 冒険者評議会からの認可取得

**DM負担**: 低（小規模ダンジョン、シンプルな依頼）

#### Phase 2: 独立ギルド時代（レベル5-10）

**転機**: 自分たちのギルドハウス（Bastion）を設立

**活動内容**:
- 中規模ダンジョン攻略
- ギルドハウスの拡張（Bastionシステム）
- ギルド依頼の受注
- 名声の獲得
- 都市政治への関与

**Bastionの成長**:
- レベル5: 基本ギルドハウス
- レベル7: 訓練場、工房追加
- レベル9: 図書館、神殿追加
- レベル11: 要塞化

**ゴール**:
- 都市で有名なギルドになる
- ダンジョンの深部に到達
- 大きな陰謀の兆候を発見

**DM負担**: 中（Bastion管理、ギルド運営、中規模ダンジョン）

#### Phase 3: 都市の英雄時代（レベル11+）

**転機**: 都市全体を脅かす危機の発見

**活動内容**:
- 大規模ダンジョン最深部
- 都市規模の陰謀解決
- 他ギルドとの協力or対立
- 世界に影響する選択

**ゴール**:
- キャンペーンのクライマックス
- 都市の未来を決定
- 伝説のギルドになる

**DM負担**: 高（大規模戦闘、複雑なストーリー、複数勢力）

## 周辺ダンジョン設計

### 6つのテーマダンジョン

各ダンジョンは異なるDMが担当可能。レベル帯ごとにエリアを分割。

#### 1. 古代遺跡「忘れられた図書館」

**テーマ**: 知識、謎解き、古代魔法

**構成**:
- 初級エリア（レベル1-4）: 外周の書庫、簡単なパズル
- 中級エリア（レベル5-10）: 禁書庫、複雑なパズル、Construct敵
- 上級エリア（レベル11+）: 最深部の魔導書庫、強力なGuardian

**特徴**:
- 謎解き・探索重視
- 魔法アイテム報酬豊富
- Intelligence判定が重要

**DMの得意分野**: パズル、ロア、魔法

---

#### 2. 廃鉱山「深淵の鉱脈」

**テーマ**: ドワーフ遺産、鉱物、地下生物

**構成**:
- 初級エリア（レベル1-4）: 上層坑道、Goblin・Giant Rat
- 中級エリア（レベル5-10）: 中層鉱脈、Duergar・Ooze
- 上級エリア（レベル11+）: 最深鉱脈、Purple Worm・Elemental

**特徴**:
- 戦闘・探索バランス型
- 鉱物資源（Bastion建設に有用）
- 狭い空間での戦術戦

**DMの得意分野**: 戦闘、マップデザイン、ドワーフロア

---

#### 3. 呪われた森「夜の森」

**テーマ**: Fey、自然魔法、狂気

**構成**:
- 初級エリア（レベル1-4）: 森の外縁、Blightや弱いFey
- 中級エリア（レベル5-10）: 森の深部、強力なFey、契約
- 上級エリア（レベル11+）: Archfeyの宮廷、次元の歪み

**特徴**:
- ロールプレイ・社交重視
- Feyとの交渉、契約

**DMの得意分野**: ロールプレイ、NPC演技、交渉

#### 4. 水没神殿「沈黙の聖堂」

**テーマ**: 古代神、水中戦、腐敗

**構成**:

**DMの得意分野**: 環境ギミック、ホラー演出、水中戦

---

#### 5. 空中要塞「浮遊城塞」（レベル5以降）

**テーマ**: 古代魔法帝国、飛行、Elemental

**構成**:

**構成**:

### デメリット

#### 1. 初期準備の負担

**必要な準備**:
- 都市の基本設定
- 主要NPC 6-8名
- ダンジョン6つ（初級エリアのみでも）
- Phase 1のクエスト10個程度

**所要時間**: 10-15時間

**緩和策**:
- 最初は2-3ダンジョンのみ
- NPCは徐々に追加
- クエストはランダム表活用

#### 2. Phase 1とPhase 2の温度差

**問題**:
- Phase 1（レベル1-4）: Bastionなし
- Phase 2（レベル5+）: Bastion中心

**リスク**:
- Phase 1が単調に感じる可能性
- レベル5まで辿り着かない

**緩和策**:
- Phase 1を短く（6-8セッション）
- 早期にレベル5到達
- Phase 1でもギルド設立の準備を楽しく

#### 3. 複数ダンジョン管理の複雑さ

**問題**:
- 6つのダンジョンそれぞれの進行度管理
- PCがどのダンジョンに行くか予測困難
- DM交代時の引き継ぎ

**緩和策**:
- スプレッドシートで管理
- 各ダンジョンは独立設計
- DMごとに担当を固定

#### 4. Bastionシステムの学習コスト

**問題**:
- Bastionルールの理解が必要
- セッション間活動の管理
- プレイヤー・DM双方の負担

**緩和策**:
- レベル5で丁寧に導入セッション
- 簡易化した運用
- オンラインツール活用

#### 5. ストーリーとサンドボックスのバランス

**問題**:
- Phase 3の大筋と、Phase 1-2の自由度
- 強制感を出さずにストーリーを進める

**緩和策**:
- Phase 1-2は完全にサンドボックス
- Phase 3の展開はPCの行動から自然に導く
- 複数のPhase 3ルート用意

## 運用方法

### DM交代システム

#### パターンA: ダンジョン担当制（推奨）

**割り当て例**（DM 3-4名の場合）:
```
DM-Alice: 古代遺跡＋都市イベント
DM-Bob: 廃鉱山＋地下墓地
DM-Carol: 呪われた森＋水没神殿
DM-Dave: 空中要塞＋メインストーリー（Phase 3）
```

**利点**:
- 各DMが自分のダンジョンを深く作り込める
- 専門性が高まる
- 引き継ぎ最小限

**運用**:
- セッション前にDiscordで「今週は誰のダンジョン？」
- 担当DMが準備
- 他DMは気軽に参加

#### パターンB: ローテーション制

**割り当て例**:
```
第1週: DM-Alice（全ダンジョン対応）
第2週: DM-Bob（全ダンジョン対応）
第3週: DM-Carol（全ダンジョン対応）
...
```

**利点**:
- 全DMが全ダンジョンを知る
- 柔軟性が高い

**欠点**:
- 各DMの準備負担大
- 一貫性が薄れる可能性

#### パターンC: Phase担当制

**割り当て例**:
```
DM-Alice: Phase 1全体（レベル1-4）
DM-Bob: Phase 2全体（レベル5-10）
DM-Carol: Phase 3全体（レベル11+）
```

**利点**:
- Phaseごとの一貫性
- 長期的なストーリー管理

**欠点**:
- DM交代頻度が低い
- 特定DMへの負担集中

### ドロップイン・ドロップアウト処理

#### 欠席PC

**Phase 1**:
「別の依頼を受けている」「銀の盾団の雑務」

**Phase 2**:
「ギルドハウスで別任務」
- Bastionアクション実行中
- 研究、クラフト、訓練
- 他の冒険者と別ダンジョン

**Phase 3**:
「都市防衛の別戦線」「情報収集」

**報酬分配**:
- 欠席PCも一定の報酬とXP（50-75%）
- Bastionアクションの成果

#### 新規参加PC

**Phase 1**:
「銀の盾団の新人」

**Phase 2**:
「ギルドに加入希望の冒険者」「他都市から移住」

**Phase 3**:
「危機に駆けつけた協力者」「他ギルドからの援軍」

**レベル調整**:
新規PCは既存PCと同レベルで開始（DMG 2024推奨）

### セッション間の管理

#### 共有ドキュメント（推奨ツール）

**Google Docs / Notion**:
- ギルドハウス状態（Bastion）
- 各ダンジョン進行度
- 主要NPCリスト
- 重要な出来事

**Discord**:
- セッション後の簡単な報告
- 次回の予定調整
- 質疑応答

**スプレッドシート**:
- PC情報（レベル、装備、財宝）
- ダンジョン攻略状況
- Bastionアクション記録

#### セッション間活動（Bastionシステム）

**処理方法**:
1. セッション終了時に次回までのダウンタイム日数を決定
2. プレイヤーはDiscordでBastionアクションを宣言
3. DM（誰でも可）が結果を裁定
4. 次セッション開始時に結果を反映

**例**:
```
プレイヤーA: 「工房で+1武器のクラフトを試みる」
DM: 「Ok、次セッションまでに75%完成。あと1週間で完成」
```

### 長期的な負担軽減

**モジュラー設計の利点**:
- 一度作ったダンジョンは永続的に使用可能
- 他のキャンペーンでも流用
- DMが変わっても引き継げる

**ライブラリの蓄積**:
6ヶ月後には：
- ダンジョン6個×3レベル帯 = 18エリア
- クエスト50個以上
- NPC 20名以上
- 都市イベント30個以上

**準備時間の推移**:
```
開始時: 10-15時間（初期設定）
1ヶ月後: 1-2時間/セッション
3ヶ月後: 30分-1時間/セッション（ライブラリ活用）
6ヶ月後: 30分以下/セッション（ほぼ即興可能）
```

✅ **戦闘・探索・ロールプレイ全て楽しみたい**
→ 完璧にバランス

✅ **D&D 2024の新要素を活用したい**
→ Bastionシステムが中核

✅ **長期キャンペーンだが単発的なセッション**
→ Phase設計で両立

→ モジュラー設計で効率的

✅ **経験者グループ**
→ 複雑なシステムも対応可能

✅ **長く遊びたい（レベル1-15+想定）**

→ 案1の方が適切

❌ **都市部のロールプレイに興味なし**
→ 案1or案5の方が適切

❌ **Bastionシステムに興味なし**
→ 案2の方が適切

❌ **短期キャンペーン（レベル1-5のみ）**
→ Phase 2に到達しないので不向き
