# 案7: 階層型ギルド都市（モジュラークエスト設計）

## 概要

案3「メガダンジョン型迷宮都市」の世界観、案5「変化する迷宮都市」のモジュラーシステム、案4「ギルドハウス型」の共同成長要素を統合した総合案。垂直的な迷宮都市を舞台に、クエスト単位で柔軟にDM交代しながら、共同ギルドハウスを成長させる。ドロップイン・ドロップアウトに完全対応し、参加頻度に関わらず全員が楽しめる。

**キーワード**: 垂直的世界観、柔軟なDM交代、共同成長、平等性、モジュラー設計

**トーン**: ダークファンタジー（バランス型・ダーク寄り）

---

## 世界設定

### 都市名: デセント（The Descent / 下降都市）

**立地**:
- 巨大な縦穴に建設された垂直的迷宮都市
- 深淵に向かって階層状に広がる
- 上層ほど明るく安全、下層ほど暗く危険
- 最下層の深淵は未踏破

**歴史**:
- 500年前、古代文明が崩壊
- その廃墟の上に現在の都市が建設
- 冒険者たちが深層を探索し、財宝を持ち帰る
- 深層には古代の秘密が眠ると噂される

**政治体制**:
- 冒険者ギルド評議会が統治
- 3大ギルド（銀の盾団、鉄血団、碧き瞳）が権力を握る
- 新興ギルドが台頭するチャンスもある
- 自由都市、独立を維持

**社会構造**:
- 上層: 富裕層、商人、ギルド本部
- 中層: 庶民、職人、古い街区
- 下層: ほぼ無人、モンスターと遺跡のみ

**特徴**:
- 「降下」が日常: 冒険者は日々深層に挑む
- 「降下者」と「地上人」: 冒険者は尊敬される
- 魔法アイテム流通が盛ん
- 危険と富が隣り合わせ
- ダークだが活気もある

## システム設計

### 垂直的な階層構造

```
【上層エリア（レベル1-4）】
├ 安全区
│  ├ 中央市場（商店街）
│  ├ ギルド本部地区（銀の盾団など）
│  ├ 宿屋街「不眠の通り」
│  └ 神殿区（回復サービス）
├ クエストゾーン（モジュール20-30個）
│  ├ 戦闘モジュール 10個
│  ├ 探索モジュール 10個
│  └ 社交モジュール 5-10個
└ 降下口（中層への階段）

【中層エリア（レベル5-10）】
├ 半安全区
│  ├ 古い街区（廃れた区画）
│  ├ 隠者の住処
│  └ 密輸商人
├ クエストゾーン（新モジュール群）
│  ├ 古代遺跡モジュール
│  ├ 中難度戦闘モジュール
│  └ 謎めいたNPCモジュール
└ 降下口（下層への封印された門）

【下層エリア（レベル11+）】
├ 危険区（安全区なし）
├ クエストゾーン（高難度モジュール）
│  ├ 古代文明の遺産
│  ├ 強力なモンスター
│  └ 深淵の謎
└ 最深部（キャンペーンクライマックス）
```

### 共同ギルドハウスシステム

**Phase 1（レベル1-4）: ギルド見習い時代**

- **所属**: 銀の盾団（大手ギルド）
- **活動内容**:
  - 上層エリアのクエストモジュール攻略
  - ギルド依頼の遂行
  - 資金と実績の蓄積
- **ゴール**: レベル5到達＋ギルド設立資金（1000gp×人数）

**Phase 2（レベル5-10）: 独立ギルド時代**

- **転機**: 自分たちのギルドハウス設立
- **場所**: 上層エリアの廃館を改築
- **Bastionシステム（共同版）**:

  **レベル5: 基本ギルドハウス**
  - 会議室（クエスト受注）
  - 宿舎（全員が利用可能）
  - 倉庫（共同装備保管）
  - Bastion Order: 情報収集、装備修理、クエスト準備

  **レベル7: 拡張**
  - 訓練場（武器マスタリー習得加速）
  - 工房（共同クラフト）
  - 小規模図書館（呪文研究）
  - Bastion Order: 装備クラフト、訓練

  **レベル9: さらなる拡張**
  - 大図書館（古文書解読）
  - 神殿（回復サービス）
  - 拡張倉庫（宝物庫）
  - Bastion Order: 古文書研究、魔法アイテム鑑定

- **活動内容**:
  - 中層エリアのクエスト攻略
  - ギルドハウスの拡張
  - 都市での名声獲得
  - 中層への降下権取得

**Phase 3（レベル11+）: 深淵の探索者時代**

- **転機**: 下層への封印された門が開く
- **ギルドハウス最終形態**:
  - 防壁（防衛戦イベント）
  - 秘密の部屋（高レベル報酬）
  - 下層への秘密通路
  - Bastion Event: 敵勢力の襲撃
- **活動内容**:
  - 下層エリアの探索
  - 古代文明の謎解明
  - 都市全体を脅かす危機への対処
  - キャンペーンクライマックス

**共同ギルドハウスの利点**:
- 誰が参加しても同じギルドハウスを使える
- 不参加でも疎外感なし（ギルドは全員の共有資産）
- クエストクリア報酬で全員に恩恵
- セッション間活動は任意（強制ではない）

## DM交代システム

### 柔軟な割り当て方式

**基本方針**:
- クエスト単位で柔軟に交代
- 各DMの得意分野を活かす
- 負担の偏りを避ける
- 「今週は〇〇さんが良さそう」と自然に決定

**運用例**:
```
週1: 「今週は戦闘クエストやりたい」
     → DM-Aさん（戦闘得意）が「ゴブリンの巣」を準備

週2: 「謎解きダンジョン行こう」
     → DM-Bさん（謎解き得意）が「失われた図書館」を準備

週3: 「DM-Aさん忙しい？」
     → DM-Cさん（柔軟対応）が「商人との交渉」を準備

週4: 「大型ボス戦！」
     → DM-Aさん（戦闘得意）が「カルト教団のボス」を準備
```

**Discord/グループチャットでの調整**:
```
プレイヤー1: 「次回は謎解きやりたいです」
プレイヤー2: 「私も賛成」
DM-B: 「じゃあ私が『失われた図書館』モジュール準備します」
DM-A: 「了解、次回は参加者として楽しみます」
全員: 「よろしく！」
```

**DMローテーション記録**（スプレッドシート）:
```
| セッション | DM   | モジュール         | タイプ | 参加者      |
|----------|------|-------------------|--------|-------------|
| 1        | DM-A | ゴブリンの巣       | 戦闘   | 全員        |
| 2        | DM-B | 失われた図書館     | 探索   | 4名         |
| 3        | DM-C | 商人との交渉       | 社交   | 3名         |
| 4        | DM-A | カルト教団のボス   | 戦闘   | 全員        |
```

## ドロップイン・ドロップアウト処理

### 欠席PCの扱い

**Phase 1（レベル1-4）**:
- 「別のギルド依頼で忙しい」
- 「銀の盾団の雑務」
- 「体調不良で休養」
- XP・報酬：50-75%を自動付与

**Phase 2以降（レベル5+）**:
- 「ギルドハウスで別任務」
- 「Bastion Orderを実行中」
  - 例：工房でクラフト、図書館で研究、訓練場で鍛錬
- 「他の降下者グループと別クエスト」
- XP・報酬：50-75%を自動付与
- Bastion Order成果：簡易裁定（Discord上）

**自然な説明**:
世界観的に「複数のクエストが同時進行」しているため、欠席は全く問題ない。

**Phase 1**:
- 「銀の盾団の新人冒険者」
- 「他のギルドから移籍」
- レベル調整：既存PCと同レベルでスタート（DMG 2024推奨）

## D&D 2024要素の活用

### 1. 武器マスタリー

**モジュールごとの推奨マスタリー**:
- **ゴブリンの巣**（狭い空間）: Slow、Topple
- **スケルトンの墓所**（Undead）: Cleave、Topple
- **崩れた回廊**（落下危険）: Push
- **カルト教団**（密集戦闘）: Cleave、Graze
- **古代遺跡**（Construct）: Sap、Vex

**戦術の幅**:
PCが複数の武器を持ち歩き、モジュールに応じて選択

**レベル5以降の中核システム**:
- 個人ではなく共同ギルドハウス
- 全員が平等に利用可能
- セッション間活動（Bastion Order）
- クエストクリア報酬で拡張

**Bastion Order例**（任意、強制ではない）:
- 「工房で+1武器をクラフト中」
- 「図書館で古文書を解読中」
- 「訓練場で武器マスタリー習得」
- Discord上で宣言→DM簡易裁定

### 3. 新スペルと改訂スペル

**活用場面**:
- **Conjure Minor Elementals（改訂版）**: 戦闘モジュールで活躍
- **Find Familiar（強化版）**: 探索モジュールで偵察
- **Guidance（改訂版）**: 探索・社交モジュールで頻繁に使用

### 4. Species（種族）の多様性

**推奨種族と世界観統合**:
- **Human**: 都市の主要種族、上層住民

**活用**:

## セッション例

### セッション1: 「降下者への道」（レベル1、3時間）

**フック**:
デセントに到着した新人冒険者たち。銀の盾団に加入し、最初の依頼を受ける。

**構成**:
1. **都市紹介（30分）**:
   - デセントの垂直構造を説明
   - 銀の盾団ギルドマスター・セリアと面会
   - 上層エリアの主要施設紹介（市場、宿屋、神殿）

2. **最初の依頼受注（15分）**:
   - 「上層の下水道にジャイアントラットが出没」
   - 簡単な戦闘依頼

3. **モジュール：ジャイアントラットの下水道（90分）**:
   - 戦闘：Giant Rat × 4、Rat Swarm × 1
   - 探索：隠し部屋（Perception DC 12）
   - 報酬：50gp、Potion of Healing

4. **帰還と報酬（15分）**:
   - セリアから報酬と賞賛
   - 宿屋「不眠の休息」でNPCたちと交流

5. **次回へのフック（10分）**:
   - 「次は少し難しい依頼だ。準備はいいか？」

## メリット・デメリット

### メリット

#### 1. 完璧なドロップイン・ドロップアウト対応（最大の長所）

**システム的利点**:
- モジュール式なので、誰が欠席しても問題なし
- 共同ギルドハウスなので、参加頻度に関わらず平等
- 世界観的に「複数クエスト同時進行」で説明自然

**実例**:
```
セッション5: PC-A, PC-B, PC-C参加 → モジュールX攻略
セッション6: PC-B, PC-D, PC-E参加 → モジュールY攻略
※PC-Aは「別クエスト中」、全員が同じギルドハウスを使える
```

#### 2. 柔軟なDM交代（クエスト単位）

**運用の柔軟性**:
- 固定スケジュールではない
- 得意分野に応じて自然に分担
- 「今週は謎解き得意な〇〇さん」方式
- 負担の偏りを避けられる

**DMの負担軽減**:
- モジュールライブラリから選ぶだけ
- 準備時間：15-30分/セッション
- 長期的にはライブラリ蓄積で即興可能

#### 3. 垂直的世界観の魅力（案3の良さ）

**探索の楽しさ**:
- 「深層に進む」感覚
- 階層ごとに雰囲気が変わる
- 未踏破の深淵へのワクワク感
- ダークファンタジーの演出

**シンプルな設定**:
- 各階層が独立した文明ほど複雑ではない
- 準備負担を抑えつつ、垂直的魅力を維持

#### 4. 共同成長の楽しさ（案4の改良版）

**ギルドハウスの成長**:
- 全員の共有資産
- 疎外感なし
- セッション間の進行感
- D&D 2024のBastion機能を活用

**平等性**:
- 参加頻度に関わらず恩恵
- 誰が来ても使える
- セッション間活動は任意

#### 5. バランスの良さ

**3つの柱**:
- 戦闘：戦闘モジュール豊富
- 探索：謎解き、ギミック
- ロールプレイ：都市NPC、社交モジュール

**モジュールタイプの多様性**:
- 戦闘好きも満足
- 謎解き好きも満足
- ロールプレイ好きも満足

#### 6. 長期継続性

**ライブラリ蓄積効果**:
- 時間が経つほど楽になる
- 各DMが得意モジュールを追加
- 1年後には70個以上のモジュール
- ほぼ即興可能に

**Phase設計**:
- レベル1-4, 5-10, 11+と明確
- 段階的な複雑化
- 長期キャンペーンに最適

#### 7. ボトムアップ拡張が容易

**初期は最小限**:
- 都市設定はシンプル
- モジュール12個から開始
- NPC 6-8名

**後から拡張**:
- 新モジュール追加
- NPC追加
- ストーリー拡張
- プレイヤーの興味に応じて

#### 1. 初期準備負担（10-15時間）
