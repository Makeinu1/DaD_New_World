# 案2: 迷宮に囲まれた自由都市

## 概要

複数の異なるテーマを持つダンジョンに四方を囲まれた中央自由都市。都市での政治・商業・陰謀と、周辺ダンジョンでの冒険が並行して展開。プレイヤーは独立した冒険者として、好きなダンジョンを選択して挑戦できる。

**キーワード**: 選択の自由、多様性、都市生活、バランス型

---

## 世界設定

### 都市名: クロスヘイブン（仮）

**歴史**:
- 200年前、大陸交易路の中心地として建設
- 周辺に古代文明の遺跡が多数存在
- 遺跡からの財宝を目当てに冒険者が集結
- 現在、中立自由都市として繁栄

**地理的特徴**:
```
       [★ 北の廃墟]
      （古代都市遺跡）
            |
[西の森]--[中央都市]--[東の鉱山]
（妖精と獣）|（クロスヘイブン）（ドワーフ廃鉱）
            |
       [南の墓地]
     （不死者の巣窟）
```

**都市の特徴**:
- 人口: 約15,000人
- 多種族共存（Human、Elf、Dwarf、Halfling他）
- 中立を保つ評議会制
- 活発な商業と冒険者経済

## 周辺ダンジョン群

### 1. 北の廃墟「エルダリス遺跡」

**テーマ**: 古代魔法文明、謎解き

**概要**:
- 1000年前のエルフ文明の遺跡
- 魔法的罠とパズル多数
- Constructs（Animated Armor、Homunculus等）

**レベル帯**: 1-6

**特徴**:
- 探索と謎解き重視
- 戦闘は少なめだが、1戦が重い
- Arcana、Investigation技能が活躍

**ボス**:
- Phase 1（レベル1-2）: Rogue Construct
- Phase 2（レベル3-4）: Corrupted Guardian
- Phase 3（レベル5-6）: Ancient Arcane Sentinel

**報酬傾向**:
- 魔法のアイテム豊富
- 古代の知識（スペルスクロール）
- アーティファクトの手がかり

### 2. 東の鉱山「ドワーフの忘れられた鉱山」

**テーマ**: 鉱山、地下探索、Elementals

**概要**:
- 100年前に放棄されたドワーフ鉱山
- 奥深くにFire Elementalが湧き出す火源
- 貴重な鉱石が眠る

**レベル帯**: 2-7

**特徴**:
- 地下環境のハザード（落盤、ガス、暗闇）
- 環境を利用した戦闘
- Survival、Athletics技能が活躍

**ボス**:
- Phase 1（レベル2-3）: Fire Mephits群
- Phase 2（レベル4-5）: Azer Forgemaster
- Phase 3（レベル6-7）: Greater Fire Elemental

**報酬傾向**:
- 貴重な鉱石（高額）
- ドワーフ製の武器・防具
- Fire Resistance アイテム

### 3. 南の墓地「永遠の安息地」

**テーマ**: Undead、ホラー、神聖魔法

**概要**:
- 都市建設前からある古い墓地
- 最近、不死者が活性化
- Necromancerの暗躍の噂

**レベル帯**: 1-5

**特徴**:
- ホラー的雰囲気
- Undead特化
- Clerics、Paladinsが活躍
- 夜間探索で難易度上昇

**ボス**:
- Phase 1（レベル1-2）: Wight
- Phase 2（レベル3-4）: Necromancer＋Undead軍団
- Phase 3（レベル5）: Revenant（復讐の亡霊）

**報酬傾向**:
- 古代の財宝
- Holy/Radiantダメージアイテム
- 呪いのアイテム（リスク・リターン）

### 4. 西の森「妖精の迷いの森」

**テーマ**: Fey、自然、トリック

**概要**:
- 妖精界との境界が薄い森
- Fey Creatures（Pixies、Sprites、Dryads）
- 予測不可能な魔法

**レベル帯**: 1-6

**特徴**:
- 社交遭遇多め
- トリックと駆け引き
- 戦闘は避けられることも
- Persuasion、Deception、Nature技能が活躍

**ボス**:
- Phase 1（レベル1-2）: Angry Dryad
- Phase 2（レベル3-4）: Hag Coven
- Phase 3（レベル5-6）: Archfey の使者

**報酬傾向**:
- Feyの恩恵（Charmなど）
- 自然魔法のアイテム
- 情報と人脈

### 5. 追加ダンジョン（拡張用）

**地下水路「忘れられた下水道」**:
- 都市の地下
- 犯罪組織の隠れ家
- 突発的なショートセッション向き

**空中要塞「浮遊島の遺跡」**:
- レベル8以降
- 高レベル向け
- Airship等の移動手段が必要

## キャンペーン構造

### Phase 1: 新米冒険者（レベル1-4）

**目標**:
- 都市での立場確立
- 各ダンジョンの初層探索
- NPC関係構築

**典型的な流れ**:
1. 都市で情報収集・クエスト受注
2. 好きなダンジョンを選択
3. ダンジョン探索（1-2セッション）
4. 都市に帰還、報告
5. ダウンタイム活動
6. 次のクエスト

**都市でのアクティビティ**:
- 商店での買い物
- 情報収集（酒場、闇市場）
- NPCとの関係構築
- サイドクエスト

### Phase 2: 一人前冒険者（レベル5-10）

**目標**:
- ダンジョンの深部探索
- 都市政治への関与
- Bastion獲得（屋敷や店舗）

**新要素**:
- 複数ダンジョンにまたがる陰謀
- 都市の派閥間の対立
- Bastionシステム導入

**ストーリー展開**:
各ダンジョンで発見した手がかりが、より大きな陰謀を示唆：
- 「4つのダンジョンは古代の封印の一部」
- 「何者かが封印を破ろうとしている」

### Phase 3: 英雄（レベル11+）

**目標**:
- 都市と世界の脅威への対処
- 古代の陰謀の解明
- キャンペーンのクライマックス

**大筋**:
4つのダンジョンは古代の「四大元素の封印」。すべてを破ると、太古の邪悪が復活する。PCたちは各ダンジョンで封印を強化するか、逆に利用するかを選択。

## セッション例

### セッション1: 「選択の街」（レベル1、4時間）

**フック**:
PCたちは様々な理由でクロスヘイブンに到着した新米冒険者。冒険者案内所で初仕事を探す。

**構成**:
1. **導入（30分）**: 都市到着、冒険者案内所でトーランと出会い
2. **都市探索（45分）**: 自由行動、各区画の紹介、NPC紹介
3. **クエスト選択（15分）**: 4つのダンジョンの初級クエストから選択
4. **ダンジョン探索（90分）**: 選択したダンジョンの最初のエリア
5. **帰還とまとめ（30分）**: 報告、報酬、都市での一夜
6. **予備（30分）**

**選択肢**:
プレイヤーに4つのダンジョンの初級クエストを提示：
- **北の廃墟**: 「魔法的な鍵の回収」（謎解き重視）
- **東の鉱山**: 「失われた採掘道具の回収」（探索重視）
- **南の墓地**: 「不死者の鎮圧」（戦闘重視）
- **西の森**: 「失踪した商人の捜索」（社交重視）

**報酬**:
- XP: 275
- 金銭: 100-150 gp（選択による）
- 都市での評判+1
- 次回への選択肢（別のダンジョンも可）

**次回へのフック**:
選択しなかった他のダンジョンにも依頼あり。または、都市内のサイドクエスト。

## メリット・デメリット詳細

### メリット

#### 1. プレイヤーの選択の自由
- どのダンジョンに行くか選べる
- 戦闘重視 or ロールプレイ重視を選択可能
- プレイヤーの興味に応じて展開

#### 2. 多様な体験
- ダンジョンごとに異なるテーマ
- 都市パートでロールプレイ充実
- 戦闘、探索、社交のバランス

#### 3. DM交代が非常に容易
- 各DMが得意なダンジョンを担当
- 都市パート担当を別DMに
- 独立性が高い

#### 4. ボトムアップ拡張が容易
- 新しいダンジョンを追加可能
- 都市の詳細を段階的に拡張
- プレイヤーの興味に応じて開発

#### 5. 長期ストーリーと単発の両立
- 各ダンジョンは独立（単発向き）
- 全体で大きなアーク（長期向き）
- Phase 2以降でストーリーが繋がる

### デメリット

#### 1. 準備の幅広さ
- 都市＋複数ダンジョンの管理
- NPCが多数必要
- プレイヤーの選択が予測不能

**緩和策**:
- 最初は都市とダンジョン1-2個のみ詳細化
- 他は概要のみ（選ばれたら詳細化）
- DM間で分担

#### 2. プレイヤーが散らばるリスク
- 同じダンジョンに行かない可能性
- パーティ分裂

**緩和策**:
- セッション開始時にPCが集まる理由を作る
- ギルドやパーティ契約
- 報酬を調整して特定ダンジョンに誘導

#### 3. 一貫性の維持
- 複数DMの場合、設定の齟齬
- NPCの性格が変わる

**緩和策**:
- 共有ドキュメント（このGitHubリポジトリ）
- 定期的なDM間ミーティング
- 主DMが最終調整役

### メリット

#### 4. 世界の生きている感じ
- 都市が単なる休憩所ではない
- NPCが生活している
- 都市内でもストーリーが進行

#### 5. リプレイ性
- 異なるダンジョンの組み合わせ
- 別のPCで別の選択

## 運用方法

### ドロップイン・ドロップアウト

**説明**:
```
参加可能PC: 「都市に滞在中の冒険者」
不在PC: 「別のダンジョン探索中」「ダウンタイム活動中」
新規PC: 「新しく都市に到着した冒険者」
```

**柔軟な編成**:
- セッションごとに「今日はこのダンジョンに行くメンバー」を決定
- 都市パートで自然に合流・離脱
- 「○○は今日は別の用事」で自然に説明

### DM交代

**担当制（推奨）**:
```
DM-A: 北の廃墟＋都市の貴族区
DM-B: 東の鉱山＋都市の商業区
DM-C: 南の墓地＋都市の下町
DM-D: 西の森＋都市の冒険者地区
依頼者: 全体調整、都市中央広場
```

**ローテーション制**:
- 各DMが順番にセッションを担当
- 前回の続きor新しいダンジョン
- 他のDMはプレイヤーとして参加（可能なら）

**共有事項**:
- 都市の基本設定
- 主要NPCリスト
- 各ダンジョンの概要
- Phase 2以降の大筋ストーリー

### セッション記録

**形式**:
```markdown
## セッションXX: [日付]
- DM: [名前]
- PC: [参加者リスト]
- 場所: 都市 → [ダンジョン名]
- 概要: [3-4文で]
- 重要な発見: [伏線、アイテム等]
- 都市の変化: [評判、NPC関係等]
```

## 準備負担

### 初期準備（初回セッション前）

**必須**（8-10時間）:
- [ ] 都市の基本設定（各区画の概要）
- [ ] 主要NPC 5-6名（詳細）
- [ ] ダンジョン4つの概要（各1ページ）
- [ ] 1つのダンジョンの詳細（セッション1用）

**推奨**（追加4-6時間）:
- [ ] 都市マップ（簡易版）
- [ ] サブクエスト 3-4個
- [ ] 都市内ランダムイベント表
- [ ] 各ダンジョンの最初のエリア詳細

### セッションごとの準備

**最小限**（2-3時間）:
- プレイヤーが選びそうなダンジョン1つの次のエリア
- または、都市パートのイベント
- NPCの準備

**理想**（4-5時間）:
- 上記＋他のダンジョンの概要更新
- 都市での新イベント
- Phase 2へ向けた伏線

### 複数DM時の分担

**初期**:
- 各DMが1ダンジョン＋都市の1区画を担当
- 共同で都市の基本設定を決定
- 月1回のDMミーティング

**運用中**:
- 各DMが自分の担当部分を準備
- セッション前に簡単な情報共有（15分）
- Gitでドキュメント共有

## まとめ

✅ **選択の自由が好き**
