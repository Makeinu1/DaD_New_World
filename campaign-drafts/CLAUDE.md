# キャンペーンドラフト - 迷宮都市5案

このフォルダには、迷宮都市を舞台とした長期キャンペーンの5つの異なるアプローチの詳細案が含まれています。

## 📁 ドキュメント一覧

1. [draft-01-endless-labyrinth.md](draft-01-endless-labyrinth.md) - **終わらぬ地下迷宮の都**
   - ダンジョンクロール重視型
   - 古典的メガダンジョンスタイル
   - 戦闘・探索中心

2. [draft-02-free-city-dungeons.md](draft-02-free-city-dungeons.md) - **迷宮に囲まれた自由都市**
   - 都市＋周辺ダンジョン型
   - 戦闘・探索・ロールプレイのバランス型
   - ボトムアップ拡張が容易

3. [draft-03-mega-dungeon-city.md](draft-03-mega-dungeon-city.md) - **メガダンジョン型迷宮都市**
   - ダンジョン内居住区
   - 垂直方向の世界
   - 非常にユニーク

4. [draft-04-guild-bastion.md](draft-04-guild-bastion.md) - **ギルドハウス型（Bastion中心）**
   - D&D 2024のBastionシステム活用
   - 拠点成長型
   - レベル5以降が本番

5. [draft-05-shifting-labyrinth.md](draft-05-shifting-labyrinth.md) - **変化する迷宮都市**
   - プロシージャル生成風
   - 即興DM向き
   - リプレイ性重視

6. [draft-06-hybrid.md](draft-06-hybrid.md) - **ハイブリッド案：ギルド都市とその迷宮**
   - 案2と案4の統合
   - 最推奨案
   - 段階的成長設計

## 🎯 使い方

### 各ドキュメントの読み方
各案には以下のセクションが含まれています：

1. **概要**: コンセプトの要約
2. **世界設定**: 舞台の詳細
3. **構造**: キャンペーン全体の仕組み
4. **レベル帯別展開**: Phase 1-3の詳細
5. **セッション例**: 具体的なセッションイメージ
6. **NPC・場所例**: 実例
7. **メリット・デメリット**: 詳細分析
8. **D&D 2024要素**: 新ルールの活用方法
9. **運用方法**: DM交代、ドロップイン・ドロップアウト
10. **準備負担**: DMにとっての難易度

### 比較検討のポイント

#### グループ適合性
- ドロップイン・ドロップアウトの自然さ
- DM交代のしやすさ
- セッション単位の独立性

#### プレイスタイル
- 戦闘 vs 探索 vs ロールプレイのバランス
- 長期ストーリーの有無
- 即興のしやすさ

#### 準備負担
- 初期準備量
- セッションごとの準備時間
- 世界設定の複雑さ

#### D&D 2024活用度
- 武器マスタリー
- Bastionシステム
- 新ルール全般

### 判断基準

以下の観点で各案を評価してください：

1. **魅力度**: 自分とグループが楽しめそうか
2. **実現可能性**: 準備と運営が現実的か
3. **継続性**: 長期的に維持できそうか
4. **柔軟性**: グループの状況変化に対応できるか
5. **独自性**: 他にはない体験ができるか

## 📝 決定後の流れ

案を選択した後は：

1. 選択した案のドキュメントをベースに `campaign/concept.md` を作成
2. 初期拠点の詳細を `locations/` に作成
3. 最初のセッション案を `adventures/session-01/` に作成
4. 必要に応じて他の案の要素も取り込み

## 🤝 複数案の統合

どれか一つに絞る必要はありません。各案の良い部分を組み合わせることも推奨します。
特に「ハイブリッド案」は、案2と案4の統合例を示しています。
