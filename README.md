# D&D New World キャンペーン

D&D 2024年版ルールを使用した自作キャンペーン「New World」のリポジトリです。

## 🎲 キャンペーンについて

**構築方式**: ボトムアップ（小さな村から世界を広げる手法）
**対象レベル**: 1～（予定）
**システム**: D&D 2024 (One D&D)

### コンセプト

_※現在構築中。詳細は [campaign/concept.md](campaign/concept.md) を参照_

## 📁 プロジェクト構成

- **campaign/**: キャンペーン全体の設定とコンセプト
- **locations/**: 村、町、ダンジョンなどの場所情報
- **npcs/**: 登場するNPC（味方、敵、中立）
- **adventures/**: セッションごとの冒険シナリオ
- **mechanics/**: 戦闘、パズル、技能チャレンジなどのメカニクス
- **dmg-2024-reference/**: DMG 2024の要点とクイックリファレンス
- **resources/**: テンプレートや参考資料

## 🎯 DMへのクイックスタート

### 初めてのDM
1. [dmg-2024-reference/](dmg-2024-reference/) でDMGの要点を学ぶ
2. [dmg-2024-reference/session-prep-checklist.md](dmg-2024-reference/session-prep-checklist.md) でセッション準備の流れを確認

### キャンペーン作成
1. [campaign/concept.md](campaign/concept.md) でキャンペーンの全体像を確認
2. [locations/starting-village/overview.md](locations/starting-village/overview.md) で初期拠点を確認
3. [dmg-2024-reference/adventure-creation-guide.md](dmg-2024-reference/adventure-creation-guide.md) で冒険の設計方法を学ぶ

### セッション準備
1. [adventures/session-01/overview.md](adventures/session-01/overview.md) で最初のセッションを準備
2. [dmg-2024-reference/dm-toolbox-reference.md](dmg-2024-reference/dm-toolbox-reference.md) を手元に用意
3. [campaign/rules/2024-features.md](campaign/rules/2024-features.md) でD&D 2024版の新要素を確認
