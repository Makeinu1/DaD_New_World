# 記憶喪失蘇生システム（Memory Loss Resurrection System）

## 概要

デセント（The Descent）における死のルールは、D&D 2024の標準ルールを改変した「記憶喪失蘇生」システムを採用する。このシステムでは、キャラクターは死亡しても自動的に蘇生するが、代償として記憶の一部を失う。

**基本哲学**：
> 「死は終わりではない。しかし、何度も死ぬたびに『自分が誰なのか』を忘れていく」

---

## 基本コンセプト

### 設計意図

このシステムは以下の問題に対処するために設計された：

1. **DMの心理的プレッシャー軽減**
   - PCを「殺してしまった」という罪悪感を軽減
   - 戦闘のランダム性による予期せぬ死への対処
   - モジュラークエスト設計での戦闘頻度増加への対応

2. **プレイヤーの安心感**
   - キャラクターロストの恐怖を軽減
   - ただし、死に意味がある（記憶喪失というペナルティ）
   - 取り返しがつく（完全な永久ロストではない）

3. **ダークファンタジー要素の強化**
   - 「自分を失う恐怖」というテーマ
   - ログホライゾンの「記憶こそが自分」という哲学
   - 蘇生できるから安心…ではない緊張感

### ログホライゾンからの影響

**原作の仕組み**：
- 死亡時に最寄りの「神殿」で復活
- 記憶の一部を喪失（大切な思い出がぼやける）
- 何度も死ぬと「自分が誰か」も曖昧に
- レベルや装備は失わない

**D&D 2024への適用**：
- 蘇生の泉（Fountain of Rebirth）で自動復活
- 記憶喪失判定（d20）でペナルティを決定
- キャンペーン全体で累積効果
- 最終的には「空っぽの冒険者」化のリスク

## D&D 2024との関係

### 「Defeated, Not Dead」の置き換え

D&D 2024 DMG の「Defeated, Not Dead」ルール（p.XXX）は、キャラクターの死を避けたいグループのための代替ルールである。デセントでは、このルールを**完全に置き換える**形で「記憶喪失蘇生」システムを採用する。

**標準ルール「Defeated, Not Dead」**：
```
- 死亡 → 1 HP + Unconscious
- Greater Restoration または DC 20 Con セーブで回復
```

**デセント版「記憶喪失蘇生」**：
```
- 死亡 → 蘇生の泉で 1 HP で復活
- 記憶喪失判定（d20）
- 記憶喪失のペナルティ（詳細は後述）
```

### 既存の蘇生呪文との共存

デセントでは、蘇生呪文（Revivify、Raise Dead等）は依然として機能するが、**効果が変更**される：

**標準ルール**：
- Revivify（3レベル）：1分以内、300gp消費、復活
- Raise Dead（5レベル）：10日以内、500gp消費、1レベル消耗、復活

**デセント版**：
- 蘇生呪文は「記憶喪失を防ぐ」または「記憶を回復する」効果に変更
- つまり：死亡 → 蘇生の泉で自動復活 → 記憶喪失判定 → 蘇生呪文で記憶喪失を打ち消し
- 低レベル（1-4）では蘇生呪文にアクセスできないため、記憶喪失は避けられない
- 高レベル（5+）では選択肢が増える（成長実感）

**利点**：
- 既存の呪文が無意味にならない
- むしろCleric/Druidの重要性が増す
- 高レベルでの選択肢の幅が広がる

### D&D 2024公式ルールとの整合性

**維持される要素**：
✅ 「死は公平でなければならない」の原則（DMG p.XXX）
✅ 「致死性の調整」（遭遇難易度で調整可能）
✅ 「死のシーン」演出（Death Save時の記憶描写）
✅ 「全員が死んだら」の対処（TPKでも蘇生、ただし記憶喪失）

**変更される要素**：
❌ 「Defeated, Not Dead」→ 「記憶喪失蘇生」に完全置き換え
❌ 標準的な蘇生呪文の効果 → 「記憶喪失を防ぐ」効果に変更

## 世界観との統合（概要）

### 降下者の契約（Descender's Contract）

デセントの冒険者ギルドは、新人冒険者に「降下者の契約」を結ばせる。これは古代文明が残した「蘇生の泉」と魂を繋ぐ魔法の契約。

**契約の文言**（簡略版）：
```
汝、深淵に降りる者よ
泉の恩恵を受けることを誓うか

死は終わりにあらず
ただし記憶の代償を払うべし

三度蘇りし者は己を失い
五度蘇りし者は名を忘れん

されど勇気ある者よ
深淵の財宝は汝を待つ
```

### 蘇生の泉（Fountain of Rebirth）

古代文明アビサル帝国の遺産。デセントの各階層に存在する。

**所在地**：
- **上層エリア**：ギルド本部の中央広場
- **中層エリア**：古い神殿跡
- **下層エリア**：古代の祭壇

**仕組み**（現時点での知識）：
- 死亡したキャラクターは自動的に最寄りの泉に引き寄せられる
- 冷たい水の感触、暗闇、そして目覚め
- 代償：記憶の一部を泉に捧げる

**謎**：
- なぜ蘇生できるのか？
- なぜ記憶が代償なのか？
- 泉に捧げられた記憶はどこへ？
- 古代文明は何を目的に？

→ **Phase 3（レベル11+）で謎が明らかに**

### 降下者と一般市民の違い

**一般市民**：
- 契約なし
- 死んだら普通に死ぬ
- 蘇生には通常の蘇生呪文が必要（高額、アクセス困難）

**降下者（PC）**：
- 契約あり
- 死んでも蘇生する
- ただし記憶を失う
- 「特別な存在」として尊敬される（同時に恐れられる）

**世界観的な意味**：
- なぜ冒険者は危険に挑むのか → 「死んでも蘇る」から
- ただし記憶喪失のリスクはある
- 「本当に大切なものを失う前に引退する」文化
- 「空っぽの冒険者」の存在（何度も死んで記憶を失った者たち）

## ルール概要

### 基本ルール

**死亡条件**（D&D 2024標準）：
- Death Saving Throw 3回失敗
- または最大HPを超えるダメージによる即死

**蘇生処理**：
1. 死亡したキャラクターは、次の自分のターン開始時（戦闘中）または1分後（戦闘外）に蘇生
2. 最寄りの蘇生の泉に出現（上層・中層・下層のいずれか）
3. 1 HPで復活、Exhaustion（消耗）レベル1を獲得
4. 記憶喪失判定を実施

### 記憶喪失判定（詳細は後で決定）

**d20を振る**：
- 1-5：重大な記憶喪失
- 6-15：中程度の記憶喪失
- 16-19：軽度の記憶喪失
- 20：記憶喪失なし（泉の恩恵）

**ペナルティ（概要）**：
- 技能判定へのペナルティ
- 一時的なスキルプロフィシエンシー喪失
- ロールプレイ要素（記憶の曖昧さ）
- 期間：軽度1セッション、中程度2セッション、重大3セッション

### 記憶の回復方法（概要）

1. **自然回復**：時間経過（1-3セッション）
2. **Greater Restoration**：5レベル呪文で即座に全回復
3. **仲間との会話**：ロールプレイでDM判断により期間短縮
4. **「記憶の断片」クエスト**：専用モジュールをクリアで回復

### 累積効果

**キャンペーン全体で死亡回数を記録**：
- 死亡回数が増えるほど、記憶喪失判定にペナルティ
- 一定回数（15-20回？）で永久的な記憶喪失のリスク
- 最終的には「空っぽの冒険者」化

**累積ペナルティの例**（暫定）：
```
死亡回数1-3回：ペナルティなし
死亡回数4-6回：記憶喪失判定に -2
死亡回数7-10回：記憶喪失判定に -4
死亡回数11-15回：記憶喪失判定に -6
死亡回数16回以上：永久的な記憶喪失の可能性
```

### 「空っぽの冒険者」

何度も死に、ほぼ全ての記憶を失った冒険者：
- 戦闘技術は残っている（レベル、クラス能力は保持）
- しかし「なぜ戦うのか」「誰のために」が分からない
- 機械的に依頼をこなす
- 目は虚ろ、感情が薄い

**NPC警告**：
ギルドマスター・セリアや他のNPCが警告役として登場。実際に「空っぽの冒険者」NPCを見せることで、プレイヤーに緊張感を与える。

## セッションでの運用（概要）

### 死亡時の処理フロー

```
1. PCが死亡条件を満たす
   ↓
2. DM: 「君は意識が遠のく…暗闇の中、冷たい水の感触」
   ↓
3. 蘇生の泉で1 HPで復活（次のターンまたは1分後）
   ↓
4. Exhaustion レベル1を獲得
   ↓
5. 記憶喪失判定（d20）
   ↓
6. 結果に応じてペナルティ適用
   ↓
7. ロールプレイ（記憶の曖昧さを演出）
```

### ロールプレイ演出

**Death Save時**（D&D 2024 "Death Scenes" p.XXX）：
- 成功時：希望や勇気を inspire する記憶
- 失敗時：恥や悲しみを喚起する記憶

**蘇生後**：
- 「頭がぼんやりする」
- 「仲間の名前が思い出せない」
- 「なぜここにいるのか分からない」

**仲間との会話**：
- 記憶を取り戻す努力
- 感動的なシーン
- DM判断で期間短縮やAdvantage付与

## メリット・デメリット

### メリット

#### 1. DMの心理的プレッシャー軽減
- PCは死なない（蘇生する）
- 「殺してしまった」罪悪感なし
- 戦闘のランダム性を恐れる必要がない

#### 2. プレイヤーの安心感
- キャラクターロストの恐怖軽減
- ただし死に意味がある（記憶喪失）
- 取り返しがつく（完全永久ロストではない）

#### 3. ダークファンタジー要素
- 「自分を失う恐怖」
- ログホライゾンの哲学
- 蘇生できるが安心ではない緊張感

#### 4. ロールプレイの深化
- 記憶喪失の演出
- 仲間との会話で回復
- 感動的なシーン創出

#### 5. 世界観統合
- 蘇生の泉の謎（メインストーリー）
- 降下者の契約（世界観の深化）
- 「空っぽの冒険者」NPC（警告）

#### 6. 既存呪文の価値向上
- Cleric/Druidの重要性増加
- Greater Restorationが非常に重要に
- 高レベルでの選択肢の幅

### デメリット

#### 1. 死の緊張感の低下
- 死んでも蘇生するため、緊張感が薄れる可能性
- **緩和策**：記憶喪失のペナルティ、累積効果

#### 2. ルールの複雑化
- 記憶喪失判定の管理
- 累積死亡回数の記録
- **緩和策**：スプレッドシートで管理、簡素化したルール

#### 3. D&D標準ルールとの乖離
- 初めてのプレイヤーには説明が必要
- 他のキャンペーンとの違い
- **緩和策**：セッション0で丁寧に説明

#### 4. 蘇生呪文の効果変更
- Revivify等の使い方が変わる
- 混乱の可能性
- **緩和策**：明確なルール文書、ハウスルールとして明示
