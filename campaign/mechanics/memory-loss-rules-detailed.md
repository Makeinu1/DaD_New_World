# 記憶喪失蘇生システム - 詳細ルール

**ゲーム運用のための完全ガイド**

---

## 概要

このドキュメントは、記憶喪失蘇生システムの詳細なゲームルールを提供します。DMとプレイヤーがセッション中に参照できるよう、具体的な数値、判定方法、ペナルティを明記しています。

**関連ドキュメント**：

- [世界観](../setting/abyssal-empire.md)（背景設定）

## 基本ルール（再掲）

### 死亡と蘇生のプロセス

1. **死亡条件**（標準D&D 2024）：
   - HP 0 → Death Saving Throws
   - 3回失敗 → 死亡

2. **自動蘇生**：
   - 降下者の契約により、最寄りの蘇生の泉で即座に復活
   - 1 HPで蘇生
   - 装備品は死亡地点に残る

3. **記憶喪失判定**：
   - 蘇生時、d20をロール
   - 結果に応じて記憶喪失の程度が決定

4. **累積効果**：
   - 死亡回数が増えるほど、記憶喪失が悪化

---

## 記憶喪失判定の詳細

### 基本判定表

蘇生時、PCは**d20をロール**します（DM裁定、または本人がロール）。

| d20ロール | 重症度 | 記憶喪失の程度 | 回復難易度 |
|----------|--------|----------------|-----------|
| 1-5      | **重度** | 重要な記憶が失われる | 困難 |
| 6-15     | **中度** | 一部の記憶が曖昧になる | 中程度 |
| 16-19    | **軽度** | わずかな記憶の欠落 | 容易 |
| 20       | **無傷** | 記憶喪失なし | - |

### 階層別修正

蘇生する泉の性能により、判定に修正が入ります。

| 蘇生場所 | 判定修正 | 備考 |
|---------|---------|------|
| **上層の泉**（レベル1-4エリア） | -2 | 基本性能、記憶喪失が多い |
| **中層の泉**（レベル5-10エリア） | ±0 | 標準性能 |
| **下層の大泉**（レベル11+エリア） | +3 | 最高性能、記憶喪失が少ない |

**例**：
- 上層の泉で蘇生、d20で「10」をロール → 10 - 2 = **8（中度）**
- 下層の大泉で蘇生、d20で「15」をロール → 15 + 3 = **18（軽度）**

### 累積ペナルティ

**死亡回数**が増えると、判定にペナルティが追加されます。

| 累積死亡回数 | 判定ペナルティ |
|------------|---------------|
| 1-3回      | ±0            |
| 4-6回      | -1            |
| 7-9回      | -2            |
| 10-12回    | -3            |
| 13-15回    | -4            |
| 16回以上   | -5            |

**例**：
- 5回目の死亡、中層の泉、d20で「12」→ 12 + 0（中層）- 1（累積）= **11（中度）**
- 10回目の死亡、中層の泉、d20で「12」→ 12 + 0（中層）- 3（累積）= **9（中度）**

**計算式**：
```
最終スコア = d20ロール + 泉の修正 - 累積ペナルティ
```

### 自動失敗・成功

- **最終スコア 0以下**：自動的に「重度」
- **ナチュラル20**：階層や累積に関わらず「無傷」（ただし累積死亡回数は増える）
- **ナチュラル1**：階層修正を無視し、自動的に「重度」

## 記憶喪失のカテゴリー

記憶喪失は、以下の**6つのカテゴリー**に分類されます。判定結果に応じて、DMがカテゴリーを選択（またはランダム決定）します。

### カテゴリー一覧

1. **戦闘記憶**：戦闘技術、武器の扱い方
2. **魔法記憶**：呪文、魔法知識
3. **技能記憶**：スキル、専門知識
4. **社交記憶**：人間関係、NPC
5. **個人記憶**：過去の出来事、自分の歴史
6. **感情記憶**：感情、性格の一部

### カテゴリー決定方法

**オプションA：DM選択**（推奨）
- DMがストーリー的に面白いカテゴリーを選ぶ
- PCのクラスや最近の出来事を考慮

**オプションB：ランダム**
- d6をロールしてカテゴリーを決定
- 完全に運任せ、予測不能

**オプションC：プレイヤー選択**
- プレイヤー自身が選ぶ（ロールプレイ重視）
- 自分のキャラクターにとって意味のある喪失を選べる

## ゲーム的ペナルティ（重症度別）

記憶喪失は、ゲームメカニクス的なペナルティとロールプレイ的なペナルティの両方を含みます。

### 軽度の記憶喪失

**全体的な影響**：
- わずかな違和感
- 日常生活に大きな支障はない
- 自然回復が早い

#### カテゴリー別の具体的効果

| カテゴリー | ゲーム的ペナルティ | ロールプレイ的効果 | 期間 |
|-----------|------------------|-------------------|------|
| **戦闘記憶** | 次の戦闘で攻撃ロール-1 | 「この武器、重いな...」 | 1戦闘 |
| **魔法記憶** | 次の呪文セーブDC -1 | 「呪文の詠唱が...思い出せない」 | 1日 |
| **技能記憶** | ランダムな1スキル判定に-2 | 「あれ、どうやるんだっけ」 | 1日 |
| **社交記憶** | 1人のNPCの名前を忘れる | 「すみません、お名前は...？」 | 3日 |
| **個人記憶** | 最近の1つの出来事を忘れる | 「昨日、何したっけ？」 | 1週間 |
| **感情記憶** | 1つの感情が鈍る | 「何も感じない...」 | 1日 |

**回復**：
- 時間経過で自然回復（上記期間後）
- Greater Restoration（即座に回復）
- ロールプレイによる回復（仲間との会話等）

### 中度の記憶喪失

**全体的な影響**：
- 明確な欠落感
- 日常に支障が出る
- 回復に時間がかかる

#### カテゴリー別の具体的効果

| カテゴリー | ゲーム的ペナルティ | ロールプレイ的効果 | 期間 |
|-----------|------------------|-------------------|------|
| **戦闘記憶** | 1つの武器の習熟を一時的に喪失 | 「この武器...使えない」 | 1週間 |
| **魔法記憶** | 準備済み呪文1つを忘れる（再準備不可） | 「その呪文...知らない」 | 3日 |
| **技能記憶** | 1つのスキル習熟を一時的に喪失 | 「やり方を...忘れた」 | 1週間 |
| **社交記憶** | 複数のNPC（3-5人）を忘れる | 「あなた...誰？」 | 2週間 |
| **個人記憶** | 重要な過去の出来事を忘れる | 「そんなこと、あったっけ？」 | 1ヶ月 |
| **感情記憶** | 特定の感情が完全に失われる | 「悲しいって...何？」 | 1週間 |

**回復**：
- 時間経過で自然回復（上記期間後）
- Greater Restoration（即座に回復）
- クエストで回復（DM裁定、特別なイベント）

### 重度の記憶喪失

**全体的な影響**：
- 深刻な欠落
- アイデンティティの一部が失われる
- 回復が困難

#### カテゴリー別の具体的効果

| カテゴリー | ゲーム的ペナルティ | ロールプレイ的効果 | 期間 |
|-----------|------------------|-------------------|------|
| **戦闘記憶** | クラス特徴1つを一時的に喪失 | 「戦い方が...分からない」 | 1ヶ月 |
| **魔法記憶** | 呪文スロット1レベル分を喪失 | 「魔法が...使えない」 | 1ヶ月 |
| **技能記憶** | 複数のスキル習熟（2-3個）を喪失 | 「何もできない...」 | 1ヶ月 |
| **社交記憶** | すべてのNPCを忘れる | 「誰も...知らない」 | 永久（※） |
| **個人記憶** | 自分の背景の一部を忘れる | 「私...誰？」 | 永久（※） |
| **感情記憶** | 性格特性1つが失われる | 「何も感じない」 | 1ヶ月 |

**※永久**：自然回復不可、クエストまたはGreater Restorationで回復可能

**回復**：
- 時間経過：一部のみ（社交・個人記憶は不可）
- Greater Restoration：即座に回復
- **特別クエスト**：「記憶の断片」クエスト（詳細後述）

### 無傷（d20で20の場合）

**効果**：
- 記憶喪失なし
- ただし累積死亡回数は増える
- ロールプレイ：「ラッキーだった...」

## 累積効果の詳細

### 死亡回数の記録

各PCの**累積死亡回数**をDMが記録します（または共有ドキュメントで公開）。

**記録例**：
```
■ PC死亡回数記録
- アラン（戦士）：3回
- エリス（魔法使い）：1回
- トーマス（盗賊）：5回（中度記憶喪失2回、軽度3回）
```

### 累積ペナルティの影響

前述の通り、死亡回数が増えると判定にペナルティが追加されます。

**重要**：累積ペナルティは**永続的**です（死亡回数はリセットされません）。

### 「空っぽの冒険者」化の閾値

**警告段階**：

| 累積死亡回数 | 状態 | 警告 |
|------------|------|------|
| 1-5回      | 正常 | なし |
| 6-10回     | 注意 | DMから「最近、記憶の欠落が多い気がする」 |
| 11-15回    | 危険 | NPCが心配し始める「大丈夫か？」 |
| 16-20回    | 臨界 | 空虚化の兆候（目が虚ろ、反応が遅い） |
| 21回以上   | **空虚化** | 「空っぽの冒険者」化のリスク |

### 空虚化判定（20回以上死亡時）

累積死亡回数が**20回**に達したPCは、次の死亡時に「空虚化判定」を行います。

**判定**：
- Wisdom Saving Throw DC 20
- 成功：空虚化を回避、通常の記憶喪失のみ
- 失敗：空虚化のプロセス開始（詳細後述）

**修正**：
- WIS修正値を適用
- Advantage：仲間の支援（同じセッション中に励ましのロールプレイがあった場合）
- Disadvantage：孤独（長期間ソロ行動）

## 回復方法の詳細

記憶喪失は以下の方法で回復できます。

### 1. 時間経過による自然回復

**軽度・中度**の記憶喪失は、時間経過で自然回復します（前述の期間参照）。

**ゲーム的処理**：
- DMが期間をトラッキング
- ダウンタイム活動として処理
- セッション間で自動回復

**重度**の一部（戦闘・魔法・技能・感情記憶）も時間経過で回復しますが、**社交・個人記憶は永久喪失**です。

### 2. Greater Restoration（5レベル呪文）

**効果の変更**（記憶喪失蘇生システム用）：

Greater Restorationは、通常の効果に加えて：
- **記憶喪失を1段階軽減**（重度→中度、中度→軽度、軽度→無傷）
- または**完全に回復**（DM裁定）

**物質要素**：ダイヤモンドの粉末（100 gp相当）（通常通り）

**ゲーム的バランス**：
- レベル5以降、ClericやDruidが重要になる
- 低レベル（1-4）では回復困難→記憶喪失が深刻
- 高レベル（5+）では管理可能→しかしコストがかかる

### 3. ロールプレイによる部分回復

**仲間との会話**：

PCが仲間と会話し、失われた記憶について話すことで、部分的に回復できます（DM裁定）。

**方法**：
- セッション中、または休息時に会話のロールプレイ
- Persuasion、Insight判定（DC 12-18、重症度による）
- 成功：記憶の断片を取り戻す（ペナルティ-1、または期間短縮）

**例**：
```
PC1（記憶喪失）：「あの戦い...何があったんだ？」
PC2：「お前は勇敢に戦ったんだ。ゴブリンの王を倒したのを覚えてないのか？」
PC1：「...そうだ、思い出した！」
DM：「Persuasion DC 15で判定してください」
PC2：（ロール）18、成功
DM：「記憶の一部が戻ってきた。攻撃ロールのペナルティが-1から±0に回復します」
```

### 4. 「記憶の断片」クエスト

**重度の記憶喪失**（特に個人記憶・社交記憶）の場合、専用のクエストで回復できます。

**クエストの例**：

#### クエスト：「失われた友」

**状況**：PCが重要なNPCを完全に忘れた

**目的**：NPCと再会し、過去の出来事を追体験する

**構成**（2-3時間のサイドクエスト）：
1. NPCがPCを訪ねてくる「覚えてないのか...？」
2. NPCが過去の冒険の場所へ案内
3. 過去の遺物を発見（写真、武器、手紙等）
4. 感動的な再会シーン
5. 記憶が完全に回復

**報酬**：
- 記憶回復
- NPCとの絆が深まる
- 感情的な満足感

#### クエスト：「自分探しの旅」

**状況**：PCが自分の背景を忘れた

**目的**：故郷や過去の場所を訪れ、自分を取り戻す

**構成**（1セッション）：
1. 故郷へ旅立つ
2. 家族や旧友と再会
3. 過去の事件の真相を知る
4. アイデンティティを再確認
5. 記憶が回復

**報酬**：
- 記憶回復
- キャラクター成長
- 新しい背景要素

## 蘇生呪文の効果変更

記憶喪失蘇生システムでは、既存の蘇生呪文の効果が変更されます。

### 基本方針

- 蘇生呪文は「死者を蘇らせる」のではなく、「記憶喪失を防ぐ」
- 降下者の契約により、PCは泉で自動蘇生する
- 蘇生呪文は、その記憶喪失を軽減または無効化する

### 呪文別の効果

#### Revivify（3レベル呪文）

**元の効果**：1分以内の死者を蘇生

**新効果**：
- 死亡から1分以内に使用可能
- **記憶喪失を完全に防ぐ**
- PCは泉ではなく、その場で1 HPで蘇生
- 記憶喪失判定なし

**物質要素**：ダイヤモンド（300 gp相当）

**ゲーム的意味**：
- 戦闘中の蘇生が可能
- 記憶喪失を完全に回避できる
- しかし高コスト

#### Raise Dead（5レベル呪文）

**元の効果**：10日以内の死者を蘇生

**新効果**：
- 死亡から10日以内に使用可能
- **記憶喪失を完全に防ぐ**
- 既に泉で蘇生した場合、失った記憶を復元
- ただし累積死亡回数は増える

**物質要素**：ダイヤモンド（500 gp相当）

**ゲーム的意味**：
- 事後的に記憶を取り戻せる
- しかし死亡回数はカウント

#### Resurrection（7レベル呪文）

**元の効果**：100年以内の死者を蘇生

**新効果**：
- 死亡から100年以内に使用可能
- **記憶喪失を完全に防ぎ、累積死亡回数も増えない**
- 既に泉で蘇生した場合、失った記憶を復元し、その死亡をカウントから除外

**物質要素**：ダイヤモンド（1,000 gp相当）

**ゲーム的意味**：
- 完全に記憶喪失のペナルティを回避
- 最高レベルの救済手段

#### True Resurrection（9レベル呪文）

**元の効果**：200年以内の死者を蘇生、肉体不要

**新効果**：
- 死亡から200年以内に使用可能
- **記憶喪失を完全に防ぎ、累積死亡回数も増えない**
- さらに、**過去の記憶喪失を1つ回復**できる
- 最も強力な記憶回復手段

**物質要素**：ダイヤモンド（25,000 gp相当）

**ゲーム的意味**：
- 最終的な救済手段
- 「空っぽの冒険者」を救う唯一の方法

### 蘇生呪文のバランス

**低レベル（1-4）**：
- 蘇生呪文なし→記憶喪失が深刻
- 緊張感が高い
- PCたちは慎重に行動

**中レベル（5-10）**：
- Revivify、Raise Deadが利用可能
- 高コストだが記憶喪失を防げる
- 戦術的な選択肢

**高レベル（11+）**：
- Resurrection、True Resurrectionが利用可能
- ほぼ完全に記憶喪失を管理可能
- しかし膨大なコスト

## 「空っぽの冒険者」化のメカニクス

### 空虚化のプロセス

累積死亡回数が20回を超え、空虚化判定（WIS Save DC 20）に失敗した場合、以下のプロセスが開始されます。

#### 段階1：初期症状（1-2セッション）

**ゲーム的効果**：
- すべての判定にDisadvantage
- 移動速度-10フィート
- リアクション使用不可

**ロールプレイ的効果**：
- 無表情になる
- 言葉数が減る
- 仲間の名前を間違える

**DM演出**：
- NPCが心配する「大丈夫か？顔色が悪いぞ」
- 仲間が異変に気づく

#### 段階2：進行（次のセッション）

**ゲーム的効果**：
- 能力値減少：INT -2、WIS -2、CHA -4
- クラス特徴を1つ喪失
- 習熟ボーナス-2

**ロールプレイ的効果**：
- ほぼ無言
- 指示されないと行動しない
- 感情がない

#### 段階3：完全な空虚化（最終段階）

**ゲーム的効果**：
- PCは完全にNPC化
- プレイヤーは新しいキャラクターを作成
- 元のPCは「空っぽの冒険者」NPCとして残る

**ロールプレイ的効果**：
- 完全に無反応
- 植物状態
- 救出クエストの対象

### 空虚化の防止

**段階1-2の間に**、以下の方法で空虚化を止められます：

#### 方法1：True Resurrection

**効果**：即座に空虚化を停止、完全回復

**コスト**：25,000 gp

#### 方法2：特別クエスト「魂の救済」

**概要**（1-2セッション）：
- 大泉の中枢（下層）へ行く
- メモリウムと交渉
- 保存された記憶を取り戻す
- 空虚化を停止

**難易度**：高（レベル11+推奨）

**報酬**：
- 空虚化停止
- 累積死亡回数リセット（0に戻る）
- 感動的なストーリー

#### 方法3：仲間の献身

**概要**：
- 仲間の1人が「自分の記憶」を分け与える
- Charisma Saving Throw DC 20
- 成功：空虚化を停止、ただし献身者は中度の記憶喪失
- 失敗：両者とも記憶喪失（軽度）

**ロールプレイ的意味**：
- 深い絆の証明
- 感動的なシーン
- プレイヤー間の協力

## エッジケースの処理

### TPK（全滅）の場合

**状況**：PC全員が同時に死亡

**処理**：
1. 全員が最寄りの泉で蘇生（同時）
2. 各PCが個別に記憶喪失判定
3. 装備は全て死亡地点に残る

**ストーリー的処理**：
- 「全員が泉で目覚めた」シーンから再開
- 「何が起きたんだ...？」
- 装備回収クエストが発生（任意）

**ゲーム的バランス**：
- TPKでもゲーム続行可能
- しかし記憶喪失と装備喪失のペナルティ
- 緊張感は維持

### 契約していないPCの死亡

**状況**：降下者の契約を結んでいないPCが死亡

**処理**：
- 通常のD&D 2024死亡ルール適用
- Death Saving Throws → 失敗で永久死亡
- 蘇生には通常の蘇生呪文が必要

**理由**：
- 契約は任意（強制ではない）
- リスクを取りたくないPCの選択を尊重

### 蘇生中の再死亡

**状況**：泉で蘇生した直後（1 HP）に再度攻撃され死亡

**処理**：
- 即座に再蘇生（同じ泉）
- 記憶喪失判定を再度実行
- 累積死亡回数+1

**DM裁量**：
- 泉の周辺は通常安全（モンスターがいない）
- 特殊状況（泉が襲撃されている等）のみ発生

### 契約の強制解除

**状況**：Phase 3で契約を解除した後の死亡

**処理**：
- 通常のD&D死亡ルール
- 蘇生呪文が必要
- 記憶喪失なし

### 他のPCが蘇生呪文を使用

**状況**：死亡したPCに、仲間がRevivifyを使用

**処理**：
- 泉での自動蘇生より優先
- 記憶喪失なし
- ただし累積死亡回数は増える（Resurrectionより下位の呪文の場合）

**タイミング**：
- 死亡から1分以内（Revivify）
- それ以降は泉での自動蘇生が発動済み

## DM用クイックリファレンス

### 死亡時のチェックリスト

**PCが死亡したら**：

1. ☐ 降下者の契約の有無を確認
   - あり→自動蘇生プロセスへ
   - なし→通常の死亡ルール

2. ☐ 累積死亡回数を記録（+1）

3. ☐ 蘇生場所を決定（最寄りの泉）

4. ☐ 記憶喪失判定
   - d20ロール
   - 泉の修正を適用
   - 累積ペナルティを適用
   - 最終スコアを確認

5. ☐ 記憶喪失の重症度を決定
   - 重度、中度、軽度、無傷

6. ☐ 記憶喪失のカテゴリーを決定
   - DM選択、ランダム、またはプレイヤー選択

7. ☐ ゲーム的ペナルティを適用
   - 数値、期間を記録

8. ☐ ロールプレイで演出
   - 「泉で目覚めるシーン」
   - 「何かを失った感覚」

9. ☐ 累積死亡回数が20回以上か確認
   - はい→空虚化判定の警告
   - いいえ→通常通り

- ☐ 回復期間をチェック（時間経過）

**セッション中**：

- ☐ 次回への伏線を準備

## プレイヤー向けガイド

### 記憶喪失を避けるために

**戦術的アプローチ**：
1. **慎重な戦闘**：無謀な突撃を避ける
2. **回復の確保**：ヒーラーを優先保護
3. **撤退の判断**：勝てない戦いは逃げる
4. **装備の充実**：防具、ポーションを整える

**呪文の活用**（中レベル以降）**：
1. **Revivify準備**：常にダイヤモンドを携帯（300 gp）
2. **Greater Restoration**：記憶喪失の治療用

**ロールプレイ的アプローチ**：
1. **仲間との絆**：会話で記憶を共有
2. **日記をつける**：失っても記録が残る
3. **大切なものを持つ**：記憶の手がかり

### 記憶喪失が起きたら

**ゲーム的対応**：
1. キャラクターシートにペナルティを記録
2. 回復期間を確認
3. DMと相談して回復方法を決定

**ロールプレイ的対応**：
1. 記憶喪失を演じる（過剰にならない程度）
2. 仲間に助けを求める
3. 記憶を取り戻す過程を楽しむ

### 記憶喪失のロールプレイ例

**軽度**：
- 「あれ、この武器の握り方...こうだったっけ？」
- 「NPC名前、何だっけ...えーっと...」

**中度**：
- 「この呪文...知らないな」
- 「あなた...誰でしたっけ？」

**重度**：
- 「戦い方が...分からない」
- 「私...誰？」

## まとめ

### 記憶喪失蘇生システムの核心

このルールセットは、以下を実現します：

1. **死のペナルティ**：死には代償がある
2. **ゲーム継続性**：しかしPCは失われない
3. **ロールプレイ機会**：記憶喪失は物語になる
4. **戦術的緊張感**：プレイヤーは慎重になる
5. **成長の実感**：高レベルで記憶喪失を管理できる

### DM向け最終アドバイス

**バランス**：
- 記憶喪失を「罰」ではなく「物語の要素」として扱う
- 過度に厳しくしない（楽しさ優先）
- プレイヤーの感情を尊重

**柔軟性**：
- ルールは指針であり、絶対ではない
- ストーリー的に面白ければ修正OK
- プレイヤーと相談して調整

**ロールプレイ**：
- 記憶喪失は感動的なシーンのチャンス
- NPCとの再会、仲間との絆
- Phase 3での大きな選択
