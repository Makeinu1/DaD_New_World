# D&D 2024版 新要素の活用

このドキュメントでは、D&D 2024年版（One D&D）の新要素をキャンペーンでどのように活用するかをまとめます。

## 武器マスタリー (Weapon Mastery)

### 概要
特定のクラス（ファイター、バーバリアン、パラディン、レンジャー、ローグ）が、
武器の特殊な技術「マスタリー」を習得できるようになりました。

### キャンペーンでの活用

#### 戦術的な選択肢
- 敵のポジショニングを考慮した武器選択
- 環境を利用した戦闘シーンの設計
- マスタリーを活かせる戦闘遭遇の配置

#### 主な武器マスタリー
- **Cleave（グレイブソード等）**: 範囲攻撃的な効果
- **Graze（グレートソード等）**: ミスでもダメージ
- **Nick（ショートソード等）**: 二刀流の強化
- **Push（グレートアックス等）**: 押し出し効果
- **Sap（フレイル等）**: 次の攻撃に不利
- **Slow（ウィップ等）**: 移動速度減少
- **Topple（バトルアックス等）**: 転倒効果
- **Vex（ショートボウ等）**: 次の攻撃に有利

### シナリオへの組み込み例
```
崖際での戦闘 → Push持ちの敵が有利に
狭い通路 → Slow/Toppleで後衛を守る
多数の弱敵 → Cleaveが輝く場面
```

## 改訂されたスペル

### 主な変更点
- バランス調整されたダメージ量
- 明確化された範囲と効果
- 集中呪文の見直し

### キャンペーンでの配慮
- 新しい呪文リストに基づくNPC術者の設計
- 改訂された呪文を前提とした遭遇バランス
- プレイヤーへの呪文選択アドバイス

## 新しいクラス機能

### ファイター
- 武器マスタリーの柔軟性
- 戦術的マスターの追加

### ローグ
- Cunning Strikeの追加（機会攻撃、ノックダウンなど）
- より多様な戦術オプション

### バーバリアン
- Rage機能の調整
- サブクラスの強化
